# RQ2 formal results

This tree contains only formal inputs/observations used by the final paper
analysis, plus per-run logs. Old archived runs, caches, redundant checkpoints,
temporary MBXP chunks, mock LLM outputs, and dependency installations were
excluded.

Large JSONL files are intentionally uncompressed so reviewers can stream,
inspect, and independently analyze individual records. `SHA256SUMS.txt`
protects all released payloads.
