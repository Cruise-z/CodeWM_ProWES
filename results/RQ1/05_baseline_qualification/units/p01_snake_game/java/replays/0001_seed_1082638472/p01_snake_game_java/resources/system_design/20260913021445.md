## Implementation approach

Preserve protocol files exactly: pom.xml, src/main/java/Main.java (default package), and a single test file src/test/java/MainTest.java. Use Maven with Java 11, JUnit 5 via maven-surefire-plugin. Keep runtime entry thin and non-interactive. Separate pure domain logic (positions, snake body, movement rules, collisions, scoring) from environment/runtime (only Main and a RandomSource adapter using java.util.Random). Inject a RandomSource to control food placement deterministically in tests. Provide a canonical API via SnakeGame with immutable GameSnapshot for read-only state and a MoveOutcome enum for tick results. Tests are headless and deterministic, focus on runtime wiring through Main and representative rules: movement with reversal rejection, food consumption/growth, and collision. All classes live in default package under src/main/java without package statements.
