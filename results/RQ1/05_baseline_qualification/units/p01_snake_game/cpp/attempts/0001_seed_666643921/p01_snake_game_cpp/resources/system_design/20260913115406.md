## Implementation approach

Alice, Eve, Alex: Bob here. We will preserve protocol files exactly and build a clean, deterministic, headless-friendly Snake core in C++17 using CMake. The runtime entry is thin (src/Main.cpp). We separate pure domain entities (Board, Snake) and orchestration (Game) from the RNG boundary (IRandom/DefaultRandom) to keep tests deterministic and portable. Tests include only headers and seed the RNG. We honor strict compilation contracts: include/Types.h is the sole definition site for Position and Direction; any header that mentions either includes "Types.h" directly. include/IRandom.h declares both IRandom and DefaultRandom; src/Random.cpp includes "IRandom.h" exactly. include/IRandom.h directly includes <cstddef>, <cstdint>, and <random>, using std::size_t and std::uint32_t with a std::mt19937 data member. include/Game.h directly includes "Board.h", "IRandom.h", "Snake.h", "Types.h", <cstddef>, <deque>, and <optional>. Direction reversal is prevented; food placement uses the RNG on unoccupied cells; moving into tail is allowed only if not growing. The Game constructor validates dimensions and uses the exact initializer snake_(Position{static_cast<int>(width / 2), static_cast<int>(height / 2)}, Direction::Right, 3). CMake builds a core library from non-Main sources, links runtime and tests to it, calls enable_testing(), and registers the test. Each target_compile_options flag is a separate argument. No GUI or OS-specific behavior; tests run via ctest.

## Program call flow

sequenceDiagram
    participant R as runtime (src/Main.cpp)
    participant G as Game
    participant S as Snake
    participant B as Board
    participant RNG as IRandom/DefaultRandom
    R->>RNG: construct(seed)
    R->>G: construct(width,height,RNG)
    G->>B: init bounds
    G->>S: init centered length=3 dir=Right
    G->>G: placeFood()
    loop ticks
        R->>G: setDirection(optional)
        R->>G: tick()
        G->>S: apply pending direction
        G->>S: compute next head
        G->>B: inBounds(next)
        G->>S: wouldSelfCollide(next, grow?)
        alt eating food
            G->>S: advanceTo(next,grow=true)
            G->>G: score++ and placeFood()
        else normal move
            G->>S: advanceTo(next,grow=false)
        end
    end
    R-->>R: print summary and exit
