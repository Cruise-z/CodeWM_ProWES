## Implementation approach

Preserve protocol files exactly: requirements.txt, Main.py, tests/test_main.py. Keep Main.py thin, exposing run_demo(seed) and using only absolute imports from twenty48.game and twenty48.types. Encapsulate 2048 core in a snake_case package twenty48 with clear, acyclic modules: types.py (Direction, GameStatus), move.py (canonical pure move_line_left), board.py (Board grid, movement using move_line_left), and game.py (seeded RNG orchestration, reset, move lifecycle, scoring, status). Ensure deterministic, headless tests: move_line_left fixtures and a smoke test using run_demo(0). No GUI, I/O, or network. The line merge implementation strictly follows the zero-filter + i+=2/i+=1 algorithm described, with padding to length 4 and forbidden in-place pops.
