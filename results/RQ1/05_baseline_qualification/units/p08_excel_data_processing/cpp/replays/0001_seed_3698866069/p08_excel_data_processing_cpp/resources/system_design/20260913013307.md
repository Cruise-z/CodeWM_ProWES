## Implementation approach

Preserve protocol files exactly. Build a small, dependency-free C++17 project via CMake. Keep runtime entry thin and deterministic. Separate pure domain logic (workbook/sheet/cell, CSV parsing/serialization, filtering/sorting/aggregation, reporting) into reusable include/*.h + src/*.cpp modules. All I/O boundaries use std::istream/std::ostream so tests remain headless/offline. Tests include only headers. Provide a canonical API in two headers: ExcelCore.h (data model + CSV) and ExcelOps.h (operations + ProcessingReport). Use stable, deterministic rules for sorting, missing values, and invalid numeric parsing. Implement robust CSV parser with quoted fields and CRLF handling; exporter emits consistent quoting. Provide composable predicates and sorting specs. Aggregations (sum, count, average) ignore invalid/missing numeric cells, define behavior for empty sets deterministically.

Per-file concrete design and implementation tasks:
- CMakeLists.txt:
  - Define project with C++17 standard.
  - Add a core library target (excelcore) from src/ExcelCore.cpp and src/ExcelOps.cpp with PUBLIC include/ path.
  - Build an executable src/Main.cpp (excel_demo) linking excelcore.
  - Build a single test executable (excel_tests) from tests/test_main.cpp, link excelcore.
  - enable_testing() and add_test(NAME excel_tests COMMAND excel_tests).
- include/ExcelCore.h:
  - Declare namespace excel with:
    - struct Cell holding raw string; methods: isMissing(), asString(), parseInt(), parseDouble().
    - class Sheet managing headers, rows (vector<vector<Cell>>), name, and column name->index map. Methods: header access, hasColumn(), columnIndex(), appendRow(vector<string>), row/col counts, cell accessors, cloneWithSubsetColumns().
    - class Workbook storing named sheets; methods: addSheet(), sheetCount(), getSheetByIndex(), getSheetByName().
    - struct CSVConfig { delimiter, quote, hasHeader, trim }.
    - struct ImportResult { Sheet sheet; size_t rowsRead; size_t missingCells; }.
    - Functions: ImportResult importCSV(std::istream&, const CSVConfig&, const std::string& sheetName); void exportCSV(const Sheet&, std::ostream&, const CSVConfig&).
  - Include all needed standard headers: string, vector, unordered_map, functional, istream, ostream, optional, stdexcept.
- src/ExcelCore.cpp:
  - Implement Cell methods (missing detection, numeric parsing with whitespace trim and robust invalid detection).
  - Implement Sheet storage and manipulation: constructor(s) from headers, appendRow with size validation, name handling, column lookup with exceptions.
  - Implement Workbook store/retrieve by name/index with validation.
  - Implement CSV parsing:
    - Read lines with std::getline, strip trailing CR.
    - Parse fields respecting quotes, escaped quotes (""), delimiter inside quotes, and trimming if configured.
    - If hasHeader: first record as headers; else synthesize column names C1..Cn.
    - Build Sheet rows; track rowsRead and missingCells (empty fields after trim).
  - Implement CSV export:
    - Write header if present in Sheet.
    - Quote fields that contain delimiter, quote, newline, leading/trailing spaces. Escape quotes by doubling.
    - Emit platform-independent newlines ("\n").
- include/ExcelOps.h:
  - Declare namespace excel with:
    - enum class MissingOrder { First, Last }.
    - struct SortKey { std::string column; bool ascending; MissingOrder missing; } and struct SortSpec { std::vector<SortKey> keys; }.
    - struct ProcessingReport with counters (rows_read, rows_kept, rows_dropped, invalid_cells, missing_cells) and operations vector; methods addOperation(), merge(), toString().
    - Column selection: Sheet selectColumnsByNames(const Sheet&, const std::vector<std::string>&, ProcessingReport*);
      Sheet selectColumnsByIndices(const Sheet&, const std::vector<size_t>&, ProcessingReport*).
    - Filtering:
      - using RowPredicate = std::function<bool(const Sheet&, size_t)>.
      - Sheet filterRows(const Sheet&, const RowPredicate&, ProcessingReport*).
      - Helper predicate: RowPredicate makeNumericGreaterThan(const std::string& column, double threshold, ProcessingReport* reportForInvalidsOrNullptr).
    - Sorting: Sheet sortRows(const Sheet&, const SortSpec&, ProcessingReport*).
    - Aggregation:
      - struct AggregationResult { size_t count_valid, count_missing, count_invalid; double sum; std::optional<double> average; }.
      - AggregationResult aggregateNumeric(const Sheet&, const std::string& column, ProcessingReport*).
  - Include needed standard headers: string, vector, functional, optional, ostream, stdexcept.
- src/ExcelOps.cpp:
  - Implement ProcessingReport methods; deterministic toString() summarizing counts and operations in fixed order.
  - Implement selectColumnsByNames/Indices: validate names/indices, create new Sheet with subset columns, preserve order; update report with operation summary.
  - Implement filterRows: apply predicate for each row; build new Sheet preserving header; compute kept/dropped; update report; remain deterministic.
  - Implement makeNumericGreaterThan: resolve column index at first invocation via a captured lambda; parse double per row using Cell::parseDouble; treat missing as false; increment report->invalid_cells or report->missing_cells accordingly when provided.
  - Implement sortRows: stable_sort with comparator that evaluates keys in order; missing ordering policy explicit; when both numeric, compare numerically; else lexicographic compare; use stable_sort to ensure original order tie-breaking; update report with spec summary.
  - Implement aggregateNumeric: scan column, sum valid doubles, count missing/invalid; compute average only if count_valid>0; update report with a deterministic operation line.
- src/Main.cpp:
  - Demonstration: build CSV input via std::istringstream with headers and some missing/invalid numeric values; import with CSVConfig; compose ProcessingReport; filter rows where a numeric column > threshold using makeNumericGreaterThan; sort by a secondary column with missing last; aggregate numeric column; export to std::ostringstream; print a brief summary line and the report to std::cout; ensure program exits 0 without loops.
- tests/test_main.cpp:
  - Include only headers: include/ExcelCore.h and include/ExcelOps.h.
  - Test 1 (runtime wiring smoke): construct in-memory CSV, import, filter, sort, aggregate, export; assert row counts and that exported CSV contains expected header and row order.
  - Test 2 (core rule with missing/invalid): verify that filter predicate treats missing as false, invalid numeric increments report.invalid_cells, missing increments report.missing_cells, and aggregate ignores invalid/missing; check ProcessingReport toString() contains deterministic counts.
  - Keep total under 150 LOC, no filesystem or network.
