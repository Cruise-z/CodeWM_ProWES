## Implementation approach

Deliver a small, clean Python 3.10 repository that cleanly separates workbook domain entities from pure operations and a thin runtime entry. Preserve protocol files exactly: requirements.txt (lists only pytest), Main.py (thin entrypoint exposing run_demo()->dict), and tests/test_main.py (single concise test module with exactly three tests). Use a snake_case package named excel_processor with four modules: model.py (foundational Cell/Row/Sheet types; imports no project modules), operations.py, csv_io.py, and report.py (each may import only from .model). __init__.py re-exports only canonical public symbols. Maintain a strictly acyclic import graph: model <- {operations, csv_io, report} <- __init__ <- {Main, tests}. No reverse edges, no wildcard exports, no old names. Ensure every pure operation returns new Sheet/Row/Cell instances (no mutation of inputs). Aggregate adheres to explicit missing and numeric rules: missing means None or empty string; numeric excludes bool; sum is 0 and min/max are None when there are no numeric values. CSV I/O uses only csv and io.StringIO, works entirely in-memory, keeps all cells as strings, and raises ValueError on ragged rows. The report builder counts missing cells and sheet dimensions deterministically. All files target Python 3.10 exactly, avoid 3.11+ features. Files are kept concise (<150 LOC each). Tests are deterministic and headless and import only the canonical API from excel_processor. Full API specification (canonical signatures, return types, key semantics, and error behavior):
- excel_processor.model.Cell(value: object | None = None): mutable Cell with attribute value: object | None.
- excel_processor.model.Row(cells: list[Cell]): defensively copies input list of Cell; values() -> list[object] returns a snapshot list of contained Cell.value in order.
- excel_processor.model.Sheet(rows: list[Row]): defensively copies; classmethod from_values(values: list[list[object]]) -> Sheet constructs a Sheet by creating new Row/Cell objects; rejects ragged non-empty rows (all non-empty rows must share equal length) with ValueError; to_values() -> list[list[object]] returns a deep snapshot (primitives) of current values; row_count() -> int; column_count() -> int (0 when there are no rows); get_cell(row: int, column: int) -> Cell validates non-negative indices and raises IndexError on out-of-range; set_cell(row: int, column: int, value: object) -> None sets the value after index validation, raising IndexError on out-of-range.
- excel_processor.operations.filter_rows(sheet: Sheet, predicate: Callable[[Row], bool]) -> Sheet: produces a new Sheet containing only rows where predicate(row) is True; stable order; deep-new Row/Cell objects; does not mutate input.
- excel_processor.operations.sort_rows(sheet: Sheet, key: Callable[[Row], object], reverse: bool = False) -> Sheet: returns a new Sheet sorted stably by key(row); deep-new Row/Cell objects; input untouched.
- excel_processor.operations.aggregate_column(sheet: Sheet, column: int) -> dict[str, object]: validates column index in [0, column_count-1] else IndexError; computes: {"count": total row count, "missing": count of None or "" in target column, "numeric_count": count of numeric values (int/float, excluding bool), "sum": numeric sum or 0 when none, "min": numeric min or None, "max": numeric max or None}. Values are derived solely from the specified column; bool is excluded from numeric_count and numeric operations.
- excel_processor.csv_io.loads_csv(text: str) -> Sheet: uses io.StringIO and csv.reader to parse in-memory; all cell values are strings; empty CSV cells remain ""; raises ValueError on ragged rows (rows of differing lengths compared to the header/first row); no filesystem access.
- excel_processor.csv_io.dumps_csv(sheet: Sheet) -> str: uses io.StringIO and csv.writer to serialize Sheet.to_values() to a CSV string; no filesystem; retains string cell semantics.
- excel_processor.report.build_report(sheet: Sheet) -> dict[str, object]: returns {"row_count": sheet.row_count(), "column_count": sheet.column_count(), "missing_cells": number of cells equal to None or ""}.
- excel_processor.__init__: re-exports exactly: Cell, Row, Sheet, filter_rows, sort_rows, aggregate_column, loads_csv, dumps_csv, build_report.
Main wiring: Main.py imports exactly from excel_processor import Sheet, filter_rows, sort_rows, aggregate_column, build_report; implements run_demo()->dict that constructs a small deterministic Sheet, runs filter/sort/aggregate/report, and returns a dict result. Under if __name__ == "__main__": it prints at most one result and exits. Test scope: tests/test_main.py contains exactly three pytest tests: (1) run_demo returns a dict; (2) given the explicit four-row fixture and the literal predicate lambda row: isinstance(row.values()[0], (int, float)) and row.values()[0] >= 2, filter keeps [[3, "c"], [2, "b"]], sorting [[3],[1],[2]] ascending yields [[1],[2],[3]], and aggregate on the four-row sheet yields count=4, missing=1, numeric_count=3, sum=6, min=1, max=3; (3) loads_csv("name,value\nA,1\nB,\n") returns exactly [["name","value"],["A","1"],["B",""]], dumps_csv round-trips via loads_csv, and build_report yields row_count=3, column_count=2, missing_cells=1. Implementation order strictly follows dependencies: requirements.txt, model.py, operations.py/csv_io.py/report.py, __init__.py, Main.py, tests/test_main.py.
