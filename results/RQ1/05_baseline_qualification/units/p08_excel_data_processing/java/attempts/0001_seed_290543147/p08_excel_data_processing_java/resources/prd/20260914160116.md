## Domain Reasoning

- Spreadsheet entities: Cell, Row, Sheet, Workbook with immutable or defensive copies to avoid side effects
- ProcessingReport for deterministic counters and invalid data tracking
- CSV import/export without quoted fields; fixed header row with careful row padding
- Filtering and sorting over in-memory rows by column values, with blanks handled explicitly
- Numeric parsing via ValueParser that records invalids exactly once per attempt
- Aggregations that scan each row once, invoking ValueParser exactly once per row, ignoring blanks/invalids
- Separation of domain logic from runtime: Main orchestrates a small, fixed demonstration only

## Domain Expectations

- Cells store raw strings; blank detection uses trim().isEmpty()
- Rows map header columns to Cell values; getters return Cell.of("") for missing columns
- Filter increments rowsKept exactly once for each retained row and does not affect rowsRead/rowsWritten
- Sort comparator treats blank values as last regardless of ascending/descending
- Workbook holds named sheets and returns Optional for sheet retrieval with defensive unmodifiable sets
- CsvIO import increments rowsRead once per data row; export increments rowsWritten once per data row
- ValueParser trims input, returns null for blanks, records exactly one invalid per invalid numeric parse
- Aggregations: sum/average return 0.0 when no numeric values; min/max return null when none
