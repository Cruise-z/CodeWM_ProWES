## Domain Reasoning

- URL validation ensures scheme and host rules with explicit :// parsing
- Format parsing and extension mapping are bounded and case-insensitive
- Safe naming enforces filesystem-friendly base names and uniqueness
- Transfer boundary returns deterministic total size per URL
- Queue state machine: QUEUED -> DOWNLOADING -> COMPLETED or CANCELED/FAILED
- Tick-driven progress increments with fixed chunk size
- Cancellation freezes progress and prevents further state transitions
- No real IO: adapters and existing-files boundary abstract external systems

## Domain Expectations

- Validate URLs: only http/https, reject whitespace, host-only allowed if host present
- Parse format text into Format enum (mp4, webm, audio), map extensions .mp4/.webm/.mp3
- Sanitize base names and generate unique names with numeric suffixes when needed
- Enqueue rejects invalid URL or format without side effects
- Deterministic progress increments by min(chunk_size, remaining)
- Single active item processed per tick (first QUEUED or DOWNLOADING)
- Cancellation sets state to CANCELED and freezes progress
- APIs return defensive copies where specified (list), or pointers to const items (get)
