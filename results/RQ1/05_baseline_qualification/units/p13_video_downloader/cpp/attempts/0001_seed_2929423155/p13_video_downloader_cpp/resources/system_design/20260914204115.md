## Implementation approach

Preserve the exact 12-file protocol and C++17 build with a thin runtime entry and one concise deterministic test target. Split the core into small, self-contained headers with matching sources: URL rules, safe naming, transfer adapter, and a tick-driven queue. No external dependencies, no filesystem/network/threading/clock. Headers directly include exactly the standard headers specified. Sources include what they use. DownloadQueue.cpp directly includes both "DownloadQueue.h" and "Url.h" before calling is_valid_url/parse_format/extension_for; SafeNamer.cpp directly includes <utility> before using std::move. Enforce deterministic behavior: a fixed FakeTransferAdapter total, fixed chunk size, and single active item per tick. Tests include only headers and assert externally visible behavior.

Concrete implementation tasks (ordered by dependency):
1) CMakeLists.txt
- Enable C++17 with extensions off (set CMAKE_CXX_STANDARD 17; CMAKE_CXX_EXTENSIONS OFF).
- Build library downloader_core from exactly: src/Url.cpp; src/SafeNamer.cpp; src/Transfer.cpp; src/DownloadQueue.cpp.
- Publish include/ directory with target_include_directories for downloader_core.
- Build downloader_app from src/Main.cpp and link to downloader_core.
- Build downloader_tests from tests/test_main.cpp and link to downloader_core.
- enable_testing(); add_test(NAME downloader_tests COMMAND downloader_tests).
- No external packages or fetches.

2) include/DownloadTypes.h
- Self-contained; directly include <cstddef>, <cstdint>, <string>.
- Define exactly: enum class Format { MP4, WEBM, AUDIO }; enum class DownloadState { QUEUED, DOWNLOADING, COMPLETED, CANCELED, FAILED }; struct Progress { std::size_t bytes; std::size_t total; }; struct DownloadItem { std::uint64_t id; std::string url; Format format; std::string filename; DownloadState state; Progress progress; std::string error; }; struct EnqueueResult { bool ok; std::uint64_t id; std::string filename; std::string error; }.
- No other declarations; no dependency on other project headers.

3) include/Url.h
- Directly include <string> and "DownloadTypes.h".
- Declare: bool is_valid_url(const std::string&); bool parse_format(const std::string&, Format& out); std::string extension_for(Format).

4) src/Url.cpp
- Directly include "Url.h" and <algorithm> and <cctype>.
- is_valid_url: reject whitespace anywhere; find literal "://"; extract scheme before separator; require scheme == "http" or "https"; set host_begin = sep + 3; find next '/' at or after host_begin or use url.size(); require host_end > host_begin; path is optional. Therefore "https://" and "http:///path" invalid; both "https://example.com" and "https://example.com/clip" valid; host-only must be accepted.
- parse_format: case-insensitive accept "mp4", "webm", "audio" mapping to Format enum.
- extension_for: map to ".mp4", ".webm", ".mp3".

5) include/SafeNamer.h
- Directly include <string>, <unordered_set>, <vector>.
- Fully declare interface class IExistingFiles with virtual destructor and pure virtual bool exists(const std::string&) const = 0.
- Declare final class InMemoryExistingFiles with private std::unordered_set<std::string> names; explicit zero-arg constructor `InMemoryExistingFiles() = default;`; separate `explicit InMemoryExistingFiles(const std::vector<std::string>& initial);` (no default argument). Provide bool exists(const std::string&) const override; void add(const std::string&).
- Declare std::string sanitize_base(const std::string& base);
- Declare std::string unique_name(const std::string& base, const std::string& extension, const IExistingFiles& files, const std::unordered_set<std::string>& reserved);
- Empty instances MUST be spelled exactly `InMemoryExistingFiles files;`; tests or runtime must not use `files({})`.

6) src/SafeNamer.cpp
- Directly include "SafeNamer.h", <algorithm>, <cctype>, and <utility> (before using std::move).
- Implement InMemoryExistingFiles(const std::vector<std::string>& initial) to populate the set; exists() queries set; add() inserts.
- sanitize_base: keep [A-Za-z0-9], '-' and '_' characters; convert any other run into a single underscore; trim leading/trailing underscores; if result empty, return "download".
- unique_name: compute candidate = base + extension; if files.exists(candidate) or reserved contains candidate, then try base_2 + extension, base_3 + extension, ... until neither files nor reserved contains it; return the candidate.

7) include/Transfer.h
- Directly include <cstddef> and <string>.
- Declare interface ITransferAdapter with virtual destructor and pure virtual std::size_t total_bytes(const std::string& url) const = 0.
- Declare final class FakeTransferAdapter with explicit constructor FakeTransferAdapter(std::size_t total_bytes = 12); and override total_bytes to return the fixed value for any URL.
- No TransferSession or bytesTransferred APIs.

8) src/Transfer.cpp
- Directly include "Transfer.h" and <stdexcept>.
- Implement FakeTransferAdapter storing a private std::size_t fixed_total_; constructor validates fixed_total_ > 0 (throw std::invalid_argument on zero); total_bytes returns fixed_total_.

9) include/DownloadQueue.h
- Directly include <cstddef>, <cstdint>, <string>, <unordered_set>, <vector>, and project headers "DownloadTypes.h", "SafeNamer.h", "Transfer.h".
- Define class DownloadQueue with private members: ITransferAdapter& adapter_; const IExistingFiles& files_; std::vector<DownloadItem> items_; std::unordered_set<std::string> reserved_names_; std::uint64_t next_id_ = 1; std::size_t chunk_size_;
- Public API exactly:
  - DownloadQueue(ITransferAdapter&, const IExistingFiles&, std::size_t chunk_size = 4);
  - EnqueueResult enqueue(const std::string& url, const std::string& format_text, const std::string& desired_base);
  - bool cancel(std::uint64_t id);
  - const DownloadItem* get(std::uint64_t id) const;
  - std::vector<DownloadItem> list() const;
  - void tick();
- Semantics: enqueue validates URL and format; on failure returns ok=false and does not modify state; on success, reserves unique filename using sanitize_base + extension_for + unique_name with both files_.exists and reserved_names_; appends a QUEUED item with progress {0, adapter_.total_bytes(url)} and increments next_id_. tick processes only the first QUEUED or DOWNLOADING item: if QUEUED, transition to DOWNLOADING; then increment bytes by min(chunk_size_, total - bytes); if bytes == total mark COMPLETED. cancel sets state to CANCELED if id exists and not terminal; canceled progress remains frozen. get returns pointer to const item or nullptr; list returns defensive copy.

10) src/DownloadQueue.cpp
- Directly include "DownloadQueue.h" and "Url.h" before calling is_valid_url/parse_format/extension_for; then include <algorithm> and <stdexcept>.
- Implement constructor saving references and chunk_size_.
- enqueue: if !is_valid_url(url): return {false, 0, std::string(), std::string("invalid url")}; if !parse_format(format_text, format): return {false, 0, std::string(), std::string("invalid format")}; compute base = sanitize_base(desired_base); ext = extension_for(format); candidate = unique_name(base, ext, files_, reserved_names_); reserve by inserting candidate into reserved_names_; total = adapter_.total_bytes(url); create DownloadItem with id = next_id_, url, format, filename=candidate, state=QUEUED, progress={0,total}, error=""; push_back; ++next_id_; return {true, item.id, item.filename, std::string()};
- tick: iterate items_ from front; find first with state QUEUED or DOWNLOADING and not CANCELED/COMPLETED/FAILED; if QUEUED, set to DOWNLOADING; compute remaining = total - bytes; add = std::min(chunk_size_, remaining); bytes += add; if bytes == total, set state COMPLETED; stop after processing that one item.
- cancel(id): find by id; if not found or state is COMPLETED/CANCELED/FAILED, return false; set state to CANCELED and return true.
- get(id) const: find and return pointer to const DownloadItem or nullptr.
- list() const: return items_ by value (defensive copy).

11) src/Main.cpp
- Construct empty existing-files boundary with the literal `InMemoryExistingFiles files;` (not `files({})`).
- Construct FakeTransferAdapter adapter; DownloadQueue queue(adapter, files, 4);
- Enqueue one fixed https URL (e.g., "https://example.com/clip"), format "mp4", desired base "clip"; ignore failure handling for demo but do not loop indefinitely.
- Call tick a bounded number of times (e.g., 4) and exit returning 0; no IO, no sleeps.

12) tests/test_main.cpp
- Include only <cassert>, <vector>, "DownloadQueue.h", and "Url.h"; define exactly one int main.
- Implement four independent blocks:
  a) URL/format rules: assert is_valid_url("https://example.com"); assert(!is_valid_url("https://")); assert(!is_valid_url("http:///path")); Format f; assert(parse_format("WEBM", f) && f==Format::WEBM);
  b) Safe naming uniqueness: InMemoryExistingFiles files; files.add("clip.mp4"); FakeTransferAdapter adapter; DownloadQueue q(adapter, files); auto r = q.enqueue("https://example.com/clip", "mp4", "clip"); assert(r.ok); assert(r.filename == "clip_2.mp4");
  c) Deterministic progress: InMemoryExistingFiles files2; FakeTransferAdapter adapter2; DownloadQueue q2(adapter2, files2, 4); auto r2 = q2.enqueue("https://example.com/a", "audio", "song"); const DownloadItem* it = q2.get(r2.id); assert(it && it->progress.bytes==0 && it->progress.total==12 && it->state==DownloadState::QUEUED); q2.tick(); it = q2.get(r2.id); assert(it->progress.bytes==4 && it->state==DownloadState::DOWNLOADING); q2.tick(); it = q2.get(r2.id); assert(it->progress.bytes==8); q2.tick(); it = q2.get(r2.id); assert(it->progress.bytes==12 && it->state==DownloadState::COMPLETED);
  d) Cancellation freezes progress: InMemoryExistingFiles files3; FakeTransferAdapter adapter3; DownloadQueue q3(adapter3, files3, 4); auto r3 = q3.enqueue("https://example.com/b", "webm", "vid"); q3.tick(); const DownloadItem* it3 = q3.get(r3.id); assert(it3->progress.bytes==4 && it3->state==DownloadState::DOWNLOADING); assert(q3.cancel(r3.id)); it3 = q3.get(r3.id); assert(it3->state==DownloadState::CANCELED); q3.tick(); it3 = q3.get(r3.id); assert(it3->progress.bytes==4 && it3->state==DownloadState::CANCELED);

Notes repeatedly enforced: exact 12-file list; DownloadTypes.h solely owns types and defines Format before DownloadItem; SafeNamer.h fully defines IExistingFiles and InMemoryExistingFiles with separate zero-arg and vector constructors (no ambiguous `files({})`); Transfer.h only exposes total_bytes; DownloadQueue mutates progress directly; DownloadQueue.cpp includes "Url.h"; SafeNamer.cpp includes <utility> before std::move; URL host-only is valid; tests are deterministic and headless; CMake builds downloader_core/downloader_app/downloader_tests and registers the test.

## Program call flow

sequenceDiagram
    participant M as Main
    participant Q as DownloadQueue
    participant U as UrlApi
    participant N as SafeNamer
    participant F as ITransferAdapter
    participant E as IExistingFiles
    M->>Q: enqueue(url, "mp4", "clip")
    Q->>U: is_valid_url(url)
    U-->>Q: bool
    Q->>U: parse_format("mp4", out)
    U-->>Q: ok, Format::MP4
    Q->>U: extension_for(Format::MP4)
    U-->>Q: ".mp4"
    Q->>N: sanitize_base("clip")
    N-->>Q: "clip"
    Q->>E: exists("clip.mp4")
    E-->>Q: bool
    Q->>N: unique_name("clip", ".mp4", E, reserved)
    N-->>Q: "clip.mp4" or "clip_2.mp4"
    Q->>F: total_bytes(url)
    F-->>Q: 12
    Q-->>M: EnqueueResult{ok=true, id, filename}
    loop bounded ticks
        M->>Q: tick()
        Q->>Q: find first QUEUED/DOWNLOADING
        Q->>Q: state=DOWNLOADING (if was QUEUED)
        Q->>Q: bytes += min(chunk, remaining)
        Q->>Q: if bytes==total then COMPLETED
    end
