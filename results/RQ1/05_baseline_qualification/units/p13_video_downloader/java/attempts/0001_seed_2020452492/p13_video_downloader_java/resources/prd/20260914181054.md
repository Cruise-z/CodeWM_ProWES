## Domain Reasoning

- Video download is modeled as a queue of requests, each validated and named safely before starting
- Real transfer is abstracted via a TransferAdapter/TransferSession boundary to keep domain logic testable and offline
- Progress and cancellation are state transitions on DownloadTask; domain updates based on adapter callbacks
- Safe output naming sanitizes user-provided names and couples with selected format to generate deterministic final names
- URL validation must reject malformed inputs early to keep queue integrity
- Deterministic offline adapter produces predictable content length and chunking to allow reliable tests
- Runtime orchestration provides a canonical API to submit requests, tick progress, cancel, and inspect task states

## Domain Expectations

- Validate URLs (http/https, host present, no spaces, reasonable path) before enqueuing
- Format selection limited to known formats (e.g., MP4, MP3, WEBM) and influences output extension
- Queue lifecycle: PENDING -> RUNNING -> COMPLETED or CANCELLED/FAILED
- Progress reported as integer percentage derived from deterministic total bytes
- Cancellation halts progress and transitions to CANCELLED without completing
- Safe output naming removes unsafe characters and appends canonical extension
- Offline deterministic adapter simulates chunked transfer without network access
- Canonical API exposes task IDs, statuses, progress, and output names

## Requirement Analysis

Functional scope: A headless Video Downloader core with URL validation, format selection, queue lifecycle, progress and cancellation, safe output naming, and an offline deterministic transfer adapter for tests. Protocol preservation: Strict Java protocol with pom.xml, Main.java, and MainTest.java; Maven Surefire and JUnit Jupiter for tests. Testability: Deterministic adapter ensures stable progress; tests avoid network and filesystem writes; runtime demo is non-interactive.

Architecture overview:
- Canonical public API: VideoDownloader orchestrates a queue of DownloadTask using a TransferAdapter. Validation and naming utilities are pure functions. Formats and statuses are enums. OfflineDeterministicAdapter implements TransferAdapter and produces deterministic sessions.
- Separation of concerns: Domain (requests, tasks, queue, sanitization) is separated from transfer boundary. No filesystem writes or real network.

Full API spec (all public types/functions, exact signatures and behavior):
- class DownloadFormat
  - public static DownloadFormat fromExtension(String ext): Returns a supported format for a given extension (case-insensitive). Throws IllegalArgumentException for unsupported ext or null.
  - public String defaultExtension(): Returns canonical lowercase extension for the format (e.g., "mp4").
  - Supported enum constants: MP4, MP3, WEBM.
- class ValidationUtils
  - public static boolean isValidUrl(String url): Returns true for http/https URLs with host and optional path; rejects null/empty, spaces, invalid schemes, missing host.
  - public static String sanitizeName(String name): Returns a safe base name by stripping unsafe characters, trimming, replacing spaces with underscores, and ensuring non-empty (falls back to "download").
  - public static String withExtension(String baseName, DownloadFormat format): Returns baseName + "." + format.defaultExtension(); baseName sanitized; throws IllegalArgumentException if format is null.
- class VideoDownloadRequest
  - public static VideoDownloadRequest of(String url, DownloadFormat format, String suggestedName): Validates url/format; computes outputName via ValidationUtils; throws IllegalArgumentException on invalid input.
  - public String getUrl(): Returns original URL.
  - public DownloadFormat getFormat(): Returns format.
  - public String getSuggestedName(): Returns original suggested name.
  - public String getOutputName(): Returns sanitized name with extension; non-null.
- enum DownloadStatus: PENDING, RUNNING, COMPLETED, FAILED, CANCELLED.
- interface TransferAdapter
  - public TransferSession begin(String url, DownloadFormat format, String outputName, ProgressListener listener): Starts a session; must be non-blocking; returns a session tracking total/downloaded bytes. Throws IllegalArgumentException on invalid arguments.
- interface TransferSession
  - public boolean step(): Advances transfer by one deterministic chunk; returns false when finished or cancelled; never blocks.
  - public void cancel(): Idempotent; stops future progress.
  - public long getTotalBytes(): Deterministic total bytes for this session.
  - public long getDownloadedBytes(): Bytes transferred so far.
- interface ProgressListener
  - public void onProgress(long downloaded, long total): Called after each step; must be lightweight and exception-free.
  - public void onCompleted(): Called exactly once when transfer reaches total.
  - public void onFailed(String message): Called on failure, with message; not used by offline adapter.
- class OfflineDeterministicAdapter implements TransferAdapter
  - public TransferSession begin(...): Produces deterministic total size based on URL string hash and fixed chunk size; steps accumulate until completed; calls listener callbacks.
- class DownloadTask
  - public DownloadTask(int id, VideoDownloadRequest request): Constructs a task with PENDING status.
  - public int getId(): Returns task identifier.
  - public DownloadStatus getStatus(): Returns current status.
  - public int getProgress(): Returns percentage 0..100 based on session bytes; 0 for PENDING; 100 for COMPLETED.
  - public String getOutputName(): Returns request.getOutputName().
  - public void start(TransferAdapter adapter): Transitions to RUNNING and attaches a session with listener updates.
  - public void tick(): If RUNNING, calls session.step() and updates status when completed.
  - public void cancel(): Cancels session if RUNNING and sets status to CANCELLED.
- class VideoDownloader (canonical API)
  - public VideoDownloader(TransferAdapter adapter): Requires non-null adapter.
  - public int requestDownload(String url, DownloadFormat format, String suggestedName): Validates and enqueues; returns unique taskId; throws IllegalArgumentException on invalid input.
  - public void startPending(): Starts all PENDING tasks; safe to call multiple times.
  - public void tick(): Advances all RUNNING tasks by one step; non-blocking.
  - public void cancel(int taskId): Cancels a task if RUNNING or PENDING; PENDING moves to CANCELLED without starting.
  - public DownloadStatus getStatus(int taskId): Returns status or throws IllegalArgumentException if not found.
  - public int getProgress(int taskId): Returns progress percentage or 0 for PENDING; throws IllegalArgumentException if not found.
  - public String getOutputName(int taskId): Returns output name for the task or throws IllegalArgumentException if not found.
