## Domain Reasoning

- Entities: Ball (position, velocity, radius), Paddle (position, width), Brick (bounds, durability), Level (brick grid, progression), GameEngine (rules orchestrator).
- State transitions: time-stepped updates of ball position; collision detection and resolution with walls, paddle, and bricks; score/lives updates; level completion and reset.
- Rules: Reflect ball on wall and paddle; decrement brick durability on hit and remove when zero; increase score per destroyed brick; lose life when ball escapes bottom.
- Determinism: All updates computed from explicit inputs (e.g., paddle move commands, fixed delta time), no randomness or real-time clocks in core.
- Boundaries: No rendering/input in core logic; runtime entry demonstrates non-interactive setup and a few deterministic ticks.
- Geometry: Axis-aligned bounding boxes for paddle and bricks; circle (ball) vs AABB collision; clamp paddle within playfield.

## Domain Expectations

- Ball motion: Ball advances each tick by velocity*dt; reflects off left/right/top walls.
- Paddle control: Paddle moves left/right within bounds based on input commands; paddle collision reflects ball upward with optional horizontal tweak.
- Wall, paddle, and brick collision: Detect and resolve collisions robustly; avoid tunneling for reasonable dt by stepwise checks.
- Brick durability/removal: Bricks have hit points; on collision decrement and remove when zero; only one brick counted per tick per ball.
- Score and lives: Score increments when a brick is destroyed; lives decrement when ball passes below bottom; reset ball/paddle on life loss.
- Level completion/reset: When all bricks are destroyed, mark level complete and reset to a new layout or flag completion.
- Deterministic step function: Given same initial state and input sequence, simulation is reproducible.
- Error handling: Validate inputs (e.g., non-negative dt, field sizes, paddle movement commands) and clamp where reasonable.

- As a player, I can move the paddle left and right within the play area to intercept the ball.

- As a player, I complete a level when all bricks are cleared.
