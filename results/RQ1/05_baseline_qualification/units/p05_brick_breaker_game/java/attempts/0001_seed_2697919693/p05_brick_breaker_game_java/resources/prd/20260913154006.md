## Domain Reasoning

- Entities: Ball, Paddle, Brick, Rect (geometry), Game (orchestrates state and rules)
- Coordinate system: x rightward, y downward; vy<0 is upward, vy>0 is downward
- Paddle center semantics: getX() returns center; asRect() left edge at x - width/2.0; setX clamps center into bounds
- Collision detection: inclusive circle-rectangle using nearest-point squared distance <= radius^2
- Collision resolution: reflect velocity component along minimum penetration axis; process order walls -> paddle -> bricks
- Tick integration: single step x+=vx*dt, y+=vy*dt with dt finite and >0
- Brick durability: Brick.hit() decrements by exactly one to zero; removal if breakable and destroyed adds exactly 100 score
- Lives and reset: on bottom-out when ball touches or crosses bottom, decrement lives exactly once, set lifeLost=true, reset ball to paddle center x and y=paddle.getY()-ball.getRadius()-1.0 with negative vy

## Domain Expectations

- Game constructor exact signature: Game(double width, double height, Paddle paddle, Ball ball, java.util.List<Brick> bricks, int lives); bricks list defensively copied; retains Ball, Paddle, Brick identities
- Game life counter declared exactly as private int lives; constructor assigns this.lives=lives; getLives() returns that same mutable field
- Paddle center semantics and clamping using [width/2.0, maxX-width/2.0] for setX
- getBricks() returns an unmodifiable view or copy; tests must not mutate it
- Ball exposes package-private setPosition(double x,double y) and setVelocity(double vx,double vy) for tests
- tick(dt) validates Double.isFinite(dt) and dt>0, integrates once, then handles wall, paddle, bricks in order
- Inclusive collision and single brick hit per tick; destroyed breakable brick removed, +100 score, and levelCompleted true when bricks list is empty
- Exact bottom-out rule: if ball.getY()+ball.getRadius()>=height and lives>0, execute lives -= 1 exactly once, set lifeLost=true, ball.setPosition(paddle.getX(), paddle.getY()-ball.getRadius()-1.0), and make ball vy negative
