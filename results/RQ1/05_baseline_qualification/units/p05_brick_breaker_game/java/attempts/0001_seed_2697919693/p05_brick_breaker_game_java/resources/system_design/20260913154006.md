## Implementation approach

Preserve Maven protocol files exactly: pom.xml, src/main/java/Main.java as runtime entry, and exactly one test file at src/test/java/MainTest.java. Use Java 11 source/target with no preview features. Keep Main.java thin, headless, and non-interactive. Place all domain classes in the default package under src/main/java with no package declarations, enabling tests in the default package to access package-private methods. Model concrete domain entities (Ball, Paddle, Brick, Rect) and a Game orchestrator. Keep collision math in a small pure rule class (Collision). Game.tick(dt) validates finite dt>0, integrates once, and processes collisions in order: walls, paddle, then bricks, using inclusive circle-rectangle detection and min-penetration axis reflection. Handle bottom-out by decrementing lives exactly once, setting lifeLost, resetting ball position to the paddle center and just above the paddle with negative vy per the specified formula. Use a defensive copy for the bricks list while retaining object identities, and return an unmodifiable view from getBricks(). Expose Ball.setPosition and Ball.setVelocity as package-private for tests. No GUI or external dependencies beyond JUnit Jupiter with a Surefire version that runs JUnit 5. Tests are deterministic and headless-friendly.

## Program call flow

sequenceDiagram
    participant M as Main
    participant G as Game
    participant P as Paddle
    participant B as Ball
    participant C as Collision
    M->>P: new Paddle(...)
    M->>B: new Ball(...)
    M->>G: new Game(width,height,P,B,bricks,lives)
    M->>G: tick(dt)
    activate G
    G->>B: integrate position (x+=vx*dt, y+=vy*dt)
    G->>G: handle walls (left/right/top reflect; bottom-out life reset)
    G->>P: asRect() for paddle collision
    G->>C: circleIntersectsRect(B, P.asRect())
    C-->>G: boolean + penetration axes
    G->>B: reflect velocity on min-penetration axis if collided
    loop for each brick (stop after first hit)
        G->>C: circleIntersectsRect(B, brick.rect)
        C-->>G: boolean + penetration axes
        alt hit
            G->>B: reflect velocity on min axis
            G->>brick: hit()
            G->>G: if brick destroyed & breakable -> remove, score+=100
        end
    end
    G-->>M: state updated (score/lives/flags)
    deactivate G
