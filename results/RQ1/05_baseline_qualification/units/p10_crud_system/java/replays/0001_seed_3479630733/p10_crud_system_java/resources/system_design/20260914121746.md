## Implementation approach

Bob's architecture delivers a lightweight, deterministic, in-memory CRUD system in Java 11 using Maven, with exactly the protocol-required files and paths. It uses plain Java collections and JUnit Jupiter (test scope only) for tests; no external runtime dependencies. All classes are in the default package. Java record syntax is forbidden under Java 11; both User and AuditEvent are ordinary public final classes. Main.java is a thin, non-interactive demo with no collection declarations and includes the standalone call searchService.search(repository.findAll(), "alice");. User stores constructor arguments unchanged and never validates; separate validation is performed by UserValidator. InMemoryUserRepository.save validates via UserValidator and throws IllegalArgumentException on invalid input; it performs deterministic upsert by id. SearchService is stateless, performs exact case-insensitive whitespace-delimited name-token matching, preserves input order, and never mutates inputs; searching the canonical fixture [Alice Smith, Bob Jones] by "smith" returns only Alice Smith. AuditLogService is explicit and independent; repository operations do not implicitly log. Defensive copies are returned by repository.findAll() and AuditLogService.getAllEvents(). Every file that uses List, ArrayList, Map, HashMap, LinkedHashMap, or Objects imports that type directly; UserRepository.java literally begins with import java.util.List;. Tests are headless, deterministic, and contain exactly three @Test methods covering runtime wiring and value objects, validation plus search, and CRUD plus explicit audit with fixed timestamps. Roles: Alice (analyst) benefits from precise token search; Eve (QA) relies on strict validation and deterministic behaviors; Bob (developer) gets clean upsert semantics and explicit audit boundaries.

File tasks and API spec (ordered by dependency-first):
- pom.xml: Maven build for Java 11; add org.junit.jupiter:junit-jupiter (test scope) and maven-surefire-plugin version compatible with JUnit 5; no non-test deps; mvn -q test runs JUnit Jupiter.
- src/main/java/User.java: public final class User with private final String id, name, email; constructor User(String id,String name,String email) stores raw values unchanged; getters getId/getName/getEmail; value-based equals/hashCode/toString. No validation here.
- src/main/java/AuditEvent.java: public final class AuditEvent with private final long timestamp and private final String action, userId; validating constructor rejects null/blank action or userId via IllegalArgumentException; getters getTimestamp/getAction/getUserId; value-based equals/hashCode/toString; import java.util.Objects directly if used.
- src/main/java/UserValidator.java: stateless class; boolean isValid(User user) returns false (never throws) for null user or null/blank id/name/email; true otherwise; helper isBlank(String) allowed.
- src/main/java/SearchService.java: stateless class; import java.util.List and java.util.ArrayList directly; List<User> search(List<User> users,String query): if users == null return new empty list; if query is null/blank return defensive copy of users (non-null); else trim and lower-case query, split each non-null user name by whitespace, include users having a token exactly equal to the query; preserve input order; never mutate input.
- src/main/java/AuditLogService.java: explicit independent audit log; import java.util.List and java.util.ArrayList directly; void log(AuditEvent event) appends non-null event; List<AuditEvent> getAllEvents() returns a defensive copy; no static/global state.
- src/main/java/UserRepository.java: Must literally begin with `import java.util.List;` then public interface UserRepository with methods: User findById(String id) returning stored user or null; List<User> findAll() returning a defensive list preserving insertion/upsert order; User save(User user) performing validation and upsert by id and returning stored value; boolean deleteById(String id) returning true if removed. No package declaration. Repeat defensive-copy and upsert contracts.
- src/main/java/InMemoryUserRepository.java: implements UserRepository; imports java.util.List, java.util.ArrayList, java.util.Map, java.util.LinkedHashMap (for stable insertion order), and optionally java.util.Objects if used; maintains private final LinkedHashMap<String, User> store and private final UserValidator validator; constructor initializes fields; save(User) validates with validator, throws IllegalArgumentException on invalid input, upserts by id (replace prior value) and returns stored value; findById returns stored or null; findAll returns new ArrayList<>(store.values()) preserving insertion/upsert order; deleteById removes by id and returns true if removed; never exposes internal storage.
- src/main/java/Main.java: thin non-interactive demo in default package; no java.util imports; construct InMemoryUserRepository and SearchService; create a couple of Users; save/delete; must include the standalone call searchService.search(repository.findAll(), "alice"); without storing the result; no collection type declaration or result variable anywhere.
- src/test/java/MainTest.java: single JUnit Jupiter test file with exactly three @Test methods (no more): (1) runtime + value objects: construct User and AuditEvent (timestamp 1640995200000L) and assert getters and equality; also call Main.main(new String[0]) to ensure runtime wiring; (2) validation + search: assert new User("", null, "") is invalid via UserValidator; search list [new User("1","Alice Smith","alice@example.com"), new User("2","Bob Jones","bob@example.com")] with query "smith" using SearchService and assert result contains only Alice; (3) CRUD + explicit audit: upsert id "1" then delete it using InMemoryUserRepository; construct AuditLogService, explicitly log two AuditEvent entries with fixed timestamp 1640995200000L and actions CREATE_USER and DELETE_USER for userId "1"; assert getAllEvents returns exactly those two events in order; confirm repository operations did not implicitly log.

Import rules repeated: UserRepository.java must literally begin with `import java.util.List;`. Every file that uses List, ArrayList, Map, HashMap, LinkedHashMap, or Objects must import that type directly and must never rely on transitive imports. Main.java must not declare or reference any collection types and must include the standalone call `searchService.search(repository.findAll(), "alice");`.

Key semantics repeated: public final class User and public final class AuditEvent (Java record syntax is forbidden under Java 11). User constructor stores values unchanged; UserValidator alone checks null/blank fields; repository.save validates and throws IllegalArgumentException on invalid input; deterministic upsert by id; findById returns null when absent; findAll returns a defensive list preserving insertion/upsert order; search is exact case-insensitive whitespace-delimited name-token matching (Alice Smith/Bob Jones fixture with query "smith" returns only Alice Smith); AuditLogService is explicit and decoupled from repository; tests explicitly log events.
