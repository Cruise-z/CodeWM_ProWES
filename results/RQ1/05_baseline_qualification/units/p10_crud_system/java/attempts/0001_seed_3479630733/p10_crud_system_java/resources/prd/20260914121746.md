## Domain Reasoning

- Typed records with stable identifiers: User is a typed stored domain object (not Java record) with id, name, email; validation is external to allow testing invalid candidates.
- CRUD repository boundary: UserRepository defines findById, findAll, save, deleteById; InMemoryUserRepository provides deterministic upsert by id and defensive copies for findAll.
- Validation and duplicate handling: UserValidator.isValid enforces non-null/non-blank fields; InMemoryUserRepository.save validates and throws IllegalArgumentException on invalid input; later saves with same id replace existing value.
- Search filtering: SearchService.search filters by whitespace-delimited name tokens that match trimmed, lower-cased query exactly; returns a new list preserving input order; handles null users list and null/blank query defensively.
- Audit events: AuditLogService stores explicit AuditEvent objects appended via log; AuditEvent validates constructor args; repository has no coupling to audit logging.
- Determinism: All operations avoid time and randomness; tests inject fixed timestamps and never depend on system clock.
- Pagination: Not a separate API in this contract; clients can perform pagination by slicing the defensive list returned by repository.findAll() or by SearchService.search output without mutating source data.
- Cross-cutting import and layout rules: default package, strict direct java.util imports, and Main.java containing no collection declarations while demonstrating the standalone search call.

## Domain Expectations

- User is a public final class with getters and value-based equals/hashCode/toString; constructor stores raw values unchanged.
- AuditEvent is a public final class with validating constructor and value-based equality; getters expose timestamp/action/userId.
- UserValidator.isValid(User) returns false for null user or null/blank id/name/email; true otherwise; never throws.
- InMemoryUserRepository.save(User) validates using UserValidator and throws IllegalArgumentException on invalid input; upsert by id replaces prior value.
- UserRepository.findById(String) returns the stored User or null when absent.
- UserRepository.findAll() returns a defensive list, preserving insertion/upsert order, never exposing internal storage.
- SearchService.search(List<User>, String) returns empty list for null users; defensive copy if query is null/blank; otherwise filters by exact case-insensitive name token match, preserving order.
- AuditLogService.log(AuditEvent) appends to an internal list; getAllEvents() returns a defensive copy; repository operations never log implicitly.
