## Domain Reasoning

- Text-to-binary payload framing: UTF-8 encode text, prefix with 2-byte unsigned big-endian length, append a one-byte checksum computed over the prefix-only (length+payload) using Checksum.sumMod256
- Bit-level conversion rules: bytesToBits emits eight MSB-first bits per byte; bitsToBytes must accept any bit length (including zero and non-multiples of eight) and pad the last byte with trailing zeros using the mandated allocation and bit-setting lines
- Matrix reservation and traversal: FinderPattern reserves three finder-square zones; ZigZag.traversal visits unreserved cells in a two-pass, row-serpentine order with bounded loops and exact count
- Matrix capacity and sizing: only odd sizes >= 21 accepted; capacity computed by counting false cells in the reserved mask; QRCodec auto-sizes starting literally at size = 21 and increases by 2 until capacity fits
- Encoding path: frame bits are written into traversal order; any unused cells remain false
- Decoding path: read all unreserved traversal bits (not guaranteed byte-aligned), convert all to bytes with bitsToBytes, read L from the first two bytes, compute frameLength = 2 + L + 1, Arrays.copyOf truncate to frameLength, validate checksum using prefix-only copy, then decode UTF-8
- Validation and rejection: MatrixValidator enforces size rules and finder placement; QRDetector verifies finder patterns and checksum; corrupting reserved areas makes decode fail with IllegalArgumentException
- Rendering: deterministic, side-effect-free string lines, exactly one line per matrix row

## Domain Expectations

- Checksum.sumMod256(byte[] data) treats bytes as unsigned and returns sum modulo 256
- TextEncoder.encodePayload(String) and decodePayload(byte[]) both use java.util.Arrays.copyOf(frame, frame.length - 1) as the checksum input and compare to (frame[frame.length - 1] & 0xFF); computing checksum over the complete frame is forbidden
- TextEncoder.bytesToBits(byte[]) uses exact MSB-first emission with bits[i * 8 + bit] = (bytes[i] & (1 << (7 - bit))) != 0;
- TextEncoder.bitsToBytes(boolean[]) must accept any length, allocate with byte[] result = new byte[(bits.length + 7) / 8]; and set bits via result[i / 8] |= (byte) (1 << (7 - (i % 8))); no modulo-length rejection or truncation is allowed
- FinderPattern.reservedMask(size) defines three finder areas; ZigZag.traversal(size, reserved) uses only these unreserved cells and returns an exact-length coordinate list created with int[][] result = new int[count][2]; without while loops or placeholder entries
- MatrixValidator.capacityBits(size) counts false entries in the reserved mask and may round down to a multiple of eight; does not double-count or subtract pattern areas heuristically
- QRDetector.readDataBits reads every unreserved bit; QRDetector.extractPayloadBytes truncates to frameLength and validates the truncated frame
- MainTest includes the direct nine-bit padding fixture where bits {true,false,false,false,false,false,false,false,true} produce unsigned bytes 128 and 128, and validates round-trips and corruption rejection

## User Stories

- As a developer, I can encode a short UTF-8 string into a deterministic square matrix with reserved finder patterns and data bits in zigzag traversal order
- As a developer, I can render the matrix to text where each row corresponds to exactly one output line
- As a developer, I can decode a valid matrix back to the original string, with strict checksum and finder verification
- As a developer, I get an IllegalArgumentException if the matrix is of invalid size, has corrupted finder patterns, or fails checksum validation

## Requirement Analysis

We must produce a Java 11 Maven project with the exact protocol-level files (pom.xml, src/main/java/Main.java, src/test/java/MainTest.java). Additional implementation files reside in src/main/java and all classes are in the default package. The project implements a deterministic QR-like codec with strict non-negotiable behaviors: (1) Checksum only covers the two length bytes and UTF-8 payload bytes; encode and decode both literally compute checksum over java.util.Arrays.copyOf(frame, frame.length - 1) and compare against (frame[frame.length - 1] & 0xFF). Calling Checksum.sumMod256(frame) over the complete frame is forbidden. (2) TextEncoder.bytesToBits emits eight MSB-first bits per byte using the exact line bits[i * 8 + bit] = (bytes[i] & (1 << (7 - bit))) != 0;. (3) TextEncoder.bitsToBytes(boolean[]) must accept every non-null array length, including non-multiples of eight; it must literally allocate byte[] result = new byte[(bits.length + 7) / 8]; and set bits with result[i / 8] |= (byte) (1 << (7 - (i % 8))); without rejecting or truncating partial bytes. The direct nine-bit fixture TextEncoder.bitsToBytes(new boolean[]{true,false,false,false,false,false,false,false,true}) must yield two bytes with unsigned values 128 and 128. (4) FinderPattern.reservedMask(size) defines the reserved cells for three finders; FinderPattern.place(matrix) and verify(matrix) use the same definition. ZigZag.traversal(size, reserved) is a two-pass bounded algorithm: first count only unreserved cells, allocate int[][] result = new int[count][2]; then fill via for row=0..size-1 with columns ascending on even rows and descending on odd rows, appending coordinates only for unreserved cells. It must not allocate new int[size * size][2], must not rely on index < size * size, must not use while loops, and must not leave placeholder entries. Encode and decode consume the returned traversal directly without re-filtering. (5) MatrixValidator accepts only odd sizes >= 21, and capacityBits(size) counts false cells in FinderPattern.reservedMask(size), optionally rounding down to a multiple of eight without double-counting subtractions. (6) QRDetector.readDataBits(QRMatrix) returns all unreserved bits, possibly not byte-aligned. QRDetector.extractPayloadBytes converts all bits via TextEncoder.bitsToBytes, reads the unsigned length from the first two bytes, computes int frameLength = 2 + length + 1;, then uses byte[] frame = java.util.Arrays.copyOf(bytes, frameLength); to truncate to the exact frame and validates it with TextEncoder.decodePayload(frame). Only the trailing zero-filled unused matrix suffix may be ignored. (7) QRCodec.encode(String,int), encode(String), and decode(QRMatrix) use the single framing path. Auto-size literally starts with int size = 21; and increases by 2 until capacity fits; it must not read a constant from MatrixValidator. (8) QRRenderer.render produces one deterministic line per row with no I/O. (9) Tests: MainTest uses JUnit Jupiter only, is in the default package with no imports of unnamed-package classes, and contains exactly three concise tests: (a) Main.main returns normally; (b) the nine-bit padding fixture returns unsigned 128,128; TextEncoder.decodePayload(TextEncoder.encodePayload("hello-世界")) round-trips; QRCodec.decode(QRCodec.encode("hello-世界")) round-trips; and rendering has one line per row; (c) flipping a copied finder cell [0][0] causes decode to throw IllegalArgumentException.
