## Implementation approach

Bob (Architect) will deliver a deterministic QR-like codec in Java 11 using Maven with exactly the mandated files. The runtime entry Main is thin and side-effect-free beyond a small fixed demonstration. All core logic is pure and testable, with no GUI or runtime dependencies. The single JUnit 5 test file validates padding, framing, traversal, finder verification, capacity rules, and corruption rejection. We strictly comply with the FINAL NON-NEGOTIABLE QR JAVA PADDING CHECKLIST: prefix-only checksum using java.util.Arrays.copyOf(frame, frame.length - 1); TextEncoder.bytesToBits uses the literal MSB-first emission line bits[i * 8 + bit] = (bytes[i] & (1 << (7 - bit))) != 0;; TextEncoder.bitsToBytes accepts any bit length and literally allocates byte[] result = new byte[(bits.length + 7) / 8]; and sets bits with result[i / 8] |= (byte) (1 << (7 - (i % 8)));; ZigZag.traversal performs a two-pass bounded serpentine with exact int[][] result = new int[count][2]; and no while loops; QRDetector.extractPayloadBytes reads all unreserved bits, converts all with the padding implementation, obtains L from first two bytes, computes int frameLength = 2 + length + 1;, truncates with byte[] frame = java.util.Arrays.copyOf(bytes, frameLength);, validates via TextEncoder.decodePayload(frame), and returns frame. FinderPattern.reservedMask/place/verify use a single consistent three-finder definition; QRCodec auto-size literally begins with int size = 21; and increments by 2 until capacity fits. Rendering emits exactly one line per matrix row.

Per-file tasks and contracts ordered by dependency:
1) pom.xml: Java 11 toolchain; depend on org.junit.jupiter:junit-jupiter in test scope; configure Maven Surefire to run JUnit 5; no runtime deps.
2) src/main/java/QRMatrix.java: Immutable size; boolean[][] cells; construction validating square; getters/setters; copy(); matrix-level helpers used by renderer and validators. No IO.
3) src/main/java/Checksum.java: static int sumMod256(byte[] data): sum bytes as unsigned, return sum % 256. No other functions.
4) src/main/java/ZigZag.java: static int[][] traversal(int size, boolean[][] reserved): two-pass bounded algorithm. First pass counts only unreserved cells and literally allocates int[][] result = new int[count][2];. Second pass iterates rows 0..size-1, columns ascend on even rows and descend on odd rows, appends coordinates only when not reserved. No while loops. No new int[size * size][2].
5) src/main/java/FinderPattern.java: static boolean[][] reservedMask(int size): marks three 7x7 finder squares at top-left, top-right, bottom-left; throws if size < 21 or even. static void place(QRMatrix): sets those finder cells true. static void verify(QRMatrix): ensures those exact cells are true and others in reserved mask remain reserved; throws IllegalArgumentException on mismatch.
6) src/main/java/TextEncoder.java: encodePayload(String text): UTF-8 encode; build frame [lenHi,lenLo,payload,checksum]; checksum computed ONLY over prefix via java.util.Arrays.copyOf(frame, frame.length - 1) and Checksum.sumMod256; never over the complete frame. decodePayload(byte[] frame): verify frame length equals 2+L+1; validate prefix-only checksum with the same Arrays.copyOf; return strict UTF-8 string. bytesToBits(byte[] bytes): exact MSB-first emission with bits[i * 8 + bit] = (bytes[i] & (1 << (7 - bit))) != 0;; bitsToBytes(boolean[] bits): accept any length; literally allocate byte[] result = new byte[(bits.length + 7) / 8]; and set bits via result[i / 8] |= (byte) (1 << (7 - (i % 8)));; no modulo-length rejection or truncation.
7) src/main/java/MatrixValidator.java: static void ensureValidSize(int size): only odd sizes >= 21. static int capacityBits(int size): count unreserved cells (false entries) from FinderPattern.reservedMask(size); may round down to multiple of 8; does not double-count or heuristically subtract.
8) src/main/java/QRDetector.java: readDataBits(QRMatrix): use reservedMask and ZigZag traversal to read every unreserved cell; returns possibly non-byte-aligned boolean[]. extractPayloadBytes(QRMatrix): convert all bits via TextEncoder.bitsToBytes; if fewer than 2 bytes, throw; compute length from first two bytes as unsigned; compute exactly int frameLength = 2 + length + 1;; reject insufficient bytes; literally byte[] frame = java.util.Arrays.copyOf(bytes, frameLength);; validate by TextEncoder.decodePayload(frame); return frame.
9) src/main/java/QRCodec.java: encode(String text, int size): MatrixValidator.ensureValidSize; compute reserved mask; capacityBits; TextEncoder.encodePayload; write bytesToBits into traversal order, leaving any extra cells false; FinderPattern.place; return matrix. encode(String text): auto-size literally starting with int size = 21; while capacity < frameBitsLen, size += 2; then encode(String,int). decode(QRMatrix): FinderPattern.verify; get frame via QRDetector.extractPayloadBytes; return TextEncoder.decodePayload(frame).
10) src/main/java/QRRenderer.java: render(QRMatrix): deterministic string, exactly one line per row, no IO side-effects; e.g., '#' for true and '.' for false.
11) src/main/java/Main.java: small demo: String msg = "hello-世界"; encode; render; decode; print concise result; return normally.
12) src/test/java/MainTest.java: single JUnit 5 file with exactly three tests: (1) Main.main returns normally; (2) bitsToBytes 9-bit fixture yields unsigned 128,128; direct TextEncoder.decodePayload(TextEncoder.encodePayload("hello-世界")) round-trips; QRCodec.decode(QRCodec.encode("hello-世界")) round-trips; rendering has one line per matrix row; (3) corrupting a copied finder cell [0][0] causes decode to throw IllegalArgumentException.

Allowed import/include directions: All higher-level classes depend on already-declared lower-level modules. No circular dependencies. Tests import only JUnit Jupiter and refer to classes in the default package without import statements.
