## Domain Reasoning

- Payload encoding/decoding: UTF-8 text -> bytes -> deterministic bitstream with length and checksum; reverse on decode with strict validation
- Matrix assembly/validation: fixed 21x21 grid, deterministic finder patterns and data placement; validation rejects malformed/corrupted matrices
- Bit extraction: read all non-finder cells in a stable row-major order; return raw bits for payload unpacking
- Rendering boundary: pure string ASCII rendering from a validated matrix; no I/O
- Codec orchestration: compose payload and matrix modules; detect is a safe probe returning boolean success
- Error handling: ValueError on invalid inputs, truncation, checksum mismatch, nonzero padding, or invalid matrices; detect catches and reports False

## Domain Expectations

- encode_text(text: str) -> bytes uses UTF-8 strict encoding
- pack_payload(data: bytes) -> list[int]: length(8) + data bits MSB-first + checksum(8), max 40 bytes
- unpack_payload(bits: list[int]) -> bytes: validates bit values, length <= 40, sufficient bits, checksum, and requires all trailing bits to be zero
- Matrix constants: SIZE=21, FINDER_SIZE=5; finder pattern with 1 border, 0 ring, 1 center
- Finder placement at (0,0), (0,16), (16,0); data_positions() lists all non-finder cells row-major
- build_matrix(bits) fills finders then writes bits into data positions; rejects non-bits or overflow
- extract_bits(matrix) requires validate_matrix(matrix) == True and returns all 366 non-finder bits
- codec.decode passes extract_bits(matrix) directly to unpack_payload without regrouping
- detect returns True only if decode succeeds; catches validation, checksum, and UTF-8 errors
- render returns a 21-line ASCII representation using provided on/off markers after validation

## User Stories

- As a developer, I can generate a 21x21 matrix from text and render it to ASCII for display.
- As a developer, I can decode a valid matrix back to the original UTF-8 text, including non-ASCII characters like 'hello-世界'.
- As a tester, I can detect corruption by flipping a finder bit and observe validation and detection failures.
- As an integrator, I can probe unknown matrices safely with detect() without raising exceptions.
- As a maintainer, I can rely on deterministic data placement and stable APIs for future extensions.

## Requirement Analysis

We must implement a deterministic QR-like codec with strict contracts across payload, matrix, codec, and rendering modules. The repository must adhere to the Python protocol: requirements.txt, a thin Main.py entrypoint, and a single tests/test_main.py with exactly three concise tests.
