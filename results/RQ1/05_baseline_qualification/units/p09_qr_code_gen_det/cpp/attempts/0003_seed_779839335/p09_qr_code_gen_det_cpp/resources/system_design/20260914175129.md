## Implementation approach

Preserve the exact nine-file C++17 layout with a single qr_core library exposing three focused headers: QRMatrix (fixed 21x21 matrix with strict finder markers and bounds-checked access), QRCodec (encode/decode/detect using fixed row-major non-finder bit ordering and a simple length+payload+checksum+padding wire format), and QRRenderer (ASCII rendering). Keep src/Main.cpp as a thin, deterministic demo that encodes and decodes a fixed literal and prints one concise line. Use only the C++17 standard library and CMake; no external libraries or platform-specific features. Ensure headers are self-contained with mandated includes, sources include headers by basename, and tests include headers only. Automated tests remain fully headless and deterministic, focusing on core rules (round-trip, corruption detection, rendering format, and length bounds).
