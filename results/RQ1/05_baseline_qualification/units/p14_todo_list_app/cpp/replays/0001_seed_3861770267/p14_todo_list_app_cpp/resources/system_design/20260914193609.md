## Implementation approach

Preserve the exact 13-file C++17 repository layout and protocol. Build a small core library (todo_core) with include/*.h and src/*.cpp pairs, expose only canonical public APIs, and keep src/Main.cpp as a thin non-interactive demo. Enforce strict header self-containment: each header includes only the standard headers mandated (no transitive reliance). Implement domain logic in pure, deterministic code paths without filesystem, network, threads, clocks, or randomness. Follow the mandatory include directives and ordering rules: TaskStore.h must directly include <map> before declaring its std::map<std::uint64_t, Task> tasks_; Query.cpp must directly include <set> and use std::set. In Date.cpp, declare helpers before first use (IsLeapYear before IsValidDay). Keep SortOrder as a global enum (not nested). Model validation and normalization rules exactly: Task::NormalizeTags trims and lowercases via NormalizeTag, removes empties, sorts, and deduplicates deterministically; DateRules validates exact YYYY-MM-DD ranges; empty due dates are permitted and sort after valid dates with compare_dates("", valid) > 0, compare_dates(valid, "") < 0, compare_dates("", "") == 0. Implement filter semantics (completed, min_priority, due_before, due_after, require_tags as set inclusion after normalization) and deterministic ordering (SortOrder::ByDueThenPriority then earlier date, higher priority, title, id; SortOrder::ByTitle then title, id). ITaskStore defines an in-memory persistence boundary with defensive copies. TaskManager orchestrates monotonic IDs starting at 1, validation, normalization, graceful false returns for missing ids in delete/set_completed, throws std::invalid_argument for invalid titles or dates in create/edit. Tests: one file with exactly one int main() and three independently scoped blocks; avoid braced-initializers inside assert by using named expected vectors; ensure the invalid-data block declares its own local existing_id.
