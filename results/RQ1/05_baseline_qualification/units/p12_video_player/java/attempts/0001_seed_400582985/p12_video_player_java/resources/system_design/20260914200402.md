## Implementation approach

Bob (Architect) designs a deterministic, headless Java 11 video player core that adheres strictly to the protocol: Maven build with pom.xml, single runtime entry Main.java, single JUnit Jupiter test in src/test/java/MainTest.java, all classes in the default package without package declarations, no GUI/network/filesystem/timers/randomness. The system separates pure domain logic from the thin runtime entry and tests. Playback is driven solely by a DeterministicClock with explicit advances. The PlaybackController orchestrates play/pause/stop/seek/next/previous and end-of-media transition rules, while PlayerSnapshot provides immutable views. VolumeControl enforces exact muted/unmuted and lastNonMuted assignment semantics, including assignment while muted. The tests cover exactly three deterministic scenarios: 5000ms single-item end-of-media STOPPED, two-item clamping and navigation bounds, and mute/unmute with volume restoration after setting while muted. Maven Surefire 3.x runs JUnit 5; org.junit.jupiter:junit-jupiter is test-scoped. Allowed dependency direction: MediaItem -> Playlist -> PlayerState/VolumeControl/DeterministicClock -> PlayerSnapshot/PlaybackController -> Main -> MainTest. No circular dependencies. All files remain under 220 LOC, and core logic is fully testable offline.
