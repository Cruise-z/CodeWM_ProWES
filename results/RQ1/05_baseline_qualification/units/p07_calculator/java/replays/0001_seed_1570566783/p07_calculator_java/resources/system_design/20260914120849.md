## Implementation approach

Preserve Maven protocol files exactly: pom.xml, src/main/java/Main.java, src/test/java/MainTest.java. Use Java 11 without preview features. Keep Main.java as a thin, non-interactive demo. Implement a pure, embeddable calculator core that includes a tokenizer, a recursive-descent parser/evaluator with unary minus, deterministic decimal math via double, explicit error types, and an in-memory bounded history. All implementation classes live in the default package (no package declarations) directly under src/main/java to avoid package/import mismatches. No external runtime dependencies beyond JUnit Jupiter for tests. Tests are headless, deterministic, concise (2–4 tests), and target the canonical API only.

## Program call flow

sequenceDiagram
    participant M as Main
    participant C as Calculator
    participant T as Tokenizer
    participant P as Parser
    participant H as CalculationHistory
    M->>C: evaluate("-3 + 4*2/(1-5)")
    C->>T: tokenize(expression)
    T-->>C: List<Token>
    C->>P: evaluate(tokens)
    P-->>C: double result or throws CalculatorException
    alt success
        C->>H: add(HistoryEntry success)
        C-->>M: CalculationResult(success, result)
    else error
        C->>H: add(HistoryEntry error)
        C-->>M: CalculationResult(error, message)
    end
    M->>C: history()
    C-->>M: List<HistoryEntry>
