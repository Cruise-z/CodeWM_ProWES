## Domain Reasoning

- Tokenization: Scan arithmetic expressions into tokens (numbers with optional decimals and unary signs; operators + - * /; parentheses). Ensure invalid characters and malformed numbers raise TokenizationError.
- Parsing to RPN: Use the shunting-yard algorithm to convert token streams to Reverse Polish Notation respecting operator precedence and parentheses; malformed expressions raise ParseError.
- Evaluation: Evaluate RPN via a float stack, performing +, -, *, /; division by zero and stack underflow/overflow scenarios raise EvaluationError.
- Unary sign folding: A leading + or - at the start or after an operator or left parenthesis must fold into the following number in the tokenizer, not as a separate operator token.
- History: Maintain an append-only list of (expression, result) tuples; append exactly one entry per successful evaluation.
- Public API boundary: evaluate(expression, history=None) and tokenize(expression) are the canonical entry points; errors are explicit types.
- Runtime boundary: Main.run_demo performs a non-interactive demonstration, using the canonical API and emitting at most a concise print under __name__ guard.
- Determinism and isolation: No I/O, filesystem, network, time, threads, or nondeterminism inside domain logic; tests rely solely on pure functions.

## Domain Expectations

- Tokenizer ignores whitespace and handles decimals like 2.5 and integers like 3.
- Unary + and - are folded into numbers when at the start or following an operator or '(' character.
- Operators precedence: * and / have higher precedence than + and -.
- Parentheses alter evaluation order; nested parentheses supported.
- Division by zero raises EvaluationError; malformed expressions raise ParseError; invalid characters raise TokenizationError.
- evaluate rejects blank or whitespace-only input with ParseError.
- History.add stores (expression, result) and History.records returns a list copy; len(History) returns record count.
- Public API re-exports: evaluate, tokenize, History, CalculatorError, TokenizationError, ParseError, EvaluationError.
