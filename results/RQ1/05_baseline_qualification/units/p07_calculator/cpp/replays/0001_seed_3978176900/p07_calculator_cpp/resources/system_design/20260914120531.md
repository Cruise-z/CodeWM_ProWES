## Implementation approach

Preserve protocol-required files exactly. Build a pure, testable core library exposing a single canonical public API in include/Calculator.h. Split domain concerns into concrete modules: token model, lexer, parser (shunting-yard to RPN), evaluator (RPN execution), and history. Keep src/Main.cpp as a thin, deterministic demo. Use C++17 with standard library only. Each reusable module has include/*.h and src/*.cpp pairs; headers are self-contained. CMake builds a core static library from non-Main sources, links both runtime demo and the single test to that library, enables testing, and registers the test. Tests are concise, deterministic, headless, and include only public headers.

## Program call flow

sequenceDiagram
    participant M as Main
    participant C as calc::Calculator
    participant L as calc::Lexer
    participant P as calc::Parser
    participant E as calc::Evaluator
    participant H as calc::History
    M->>C: evaluate("(1.5+2.5)/2")
    C->>L: tokenize(expr)
    L-->>C: LexResult(tokens)
    C->>P: toRPN(tokens)
    P-->>C: ParseResult(rpn)
    C->>E: evaluateRPN(rpn)
    E-->>C: EvalResult(value)
    C->>H: record(expr, value)
    H-->>C: ok
    C-->>M: EvaluationOutcome(success=true, value)
    M->>C: history()
    C-->>M: vector<HistoryEntry>
