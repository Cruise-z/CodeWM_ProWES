## Implementation approach

Bob (Architect) designs a concise, medium-size Python 3.10 repository for a deterministic Tank battle game. Preserve protocol files exactly and keep Main.py thin. All reusable logic lives in a lowercase snake_case package tank_battle. Imports are acyclic: foundational modules (directions, geometry, obstacle) do not import engines or entrypoints. Snapshot returns plain dict/list/scalars with Direction serialized via .name. Deterministic Game.tick applies queued commands with isinstance dispatch only, then moves projectiles in order during the same tick; reset restores deep initial clones and zeroed ScoreBoard with next_projectile_id=0.

Full API specification (literal, exhaustive and aligned to the non-negotiable checklist):
- Module tank_battle/directions.py:
  - from enum import Enum; class Direction(Enum): with enum members exactly: N=(0,-1), E=(1,0), S=(0,1), W=(-1,0).
  - Methods: delta(self)->tuple[int,int] returns self.value; left(self)->Direction returns enum member; right(self)->Direction returns enum member.
- Module tank_battle/geometry.py:
  - Class Rect(x:int,y:int,w:int,h:int): immutable value; raises ValueError if w<=0 or h<=0; method contains(px:int,py:int)->bool uses half-open cells x<=px<x+w and y<=py<y+h.
- Module tank_battle/obstacle.py:
  - Class Obstacle(rect:Rect) encapsulating one Rect. Provides its rect.
- Module tank_battle/arena.py:
  - Class Arena(width:int,height:int,obstacles:list[Obstacle]) rejects nonpositive dimensions; methods: in_bounds(x:int,y:int)->bool; is_blocked(x:int,y:int)->bool where out-of-bounds and any Obstacle cell are blocked.
- Module tank_battle/tank.py:
  - Class Tank(id:str,name:str,x:int,y:int,direction:Direction,health:int=3,speed:int=1). Public attributes include direction.
  - Methods: barrel_ahead()->tuple[int,int] using direction.delta(); alive()->bool; clone()->Tank deep copy.
- Module tank_battle/projectile.py:
  - Class Projectile(pid:int,owner_id:str,x:int,y:int,direction:Direction,speed:int=1) with attribute direction.
  - Methods: move()->None advances one unit using direction.delta(); clone()->Projectile deep copy.
- Module tank_battle/commands.py:
  - Class Command: instantiable marker; Command has no execute method; no ABC and no @abstractmethod.
  - Subclasses: MoveForward(steps:int=1) rejects steps<1; RotateLeft(); RotateRight(); RotateTo(direction:Direction) stores attribute direction; Fire(). None defines execute.
- Module tank_battle/scoring.py:
  - Class ScoreBoard(player_ids:list[str]) immediately initializes hits and kills as {player_id:0 for player_id in player_ids}.
  - Methods: record_hit(player_id:str)->None; record_kill(player_id:str)->None; score(player_id:str)->int defined as score(player_id)=hits+5*kills.
- Module tank_battle/game.py:
  - Must literally include the import line: from .commands import Command, MoveForward, RotateLeft, RotateRight, RotateTo, Fire
  - Class Game(arena:Arena,tanks:dict[str,Tank]) validates unique in-bounds unblocked tank cells; deep-copies and stores an immutable initial arena/tank snapshot.
  - Public mutable attributes: arena, tanks, projectiles, scores, command_queue, next_projectile_id.
  - Methods:
    - queue_command(self, player_id:str, command:Command)->None: enqueue without reordering.
    - tick(self)->None: deterministic order: stable-sort queued commands by player id; dispatch solely with isinstance(command, MoveForward/RotateLeft/RotateRight/RotateTo/Fire); apply; clear queue; then process projectiles by pid ascending. MoveForward attempts one cell at a time and stops before bounds, obstacle, or a live tank. On Fire, if barrel_ahead is free, spawn a new Projectile at that cell with owner_id:str equal to the queuing tank id and pid=self.next_projectile_id then increment; in the same tick's projectile phase, every projectile including the new one moves by its speed one cell at a time; after each unit step, despawn on bounds/obstacle or if hitting the first non-owner live tank at that cell, reduce health by 1, call self.scores.record_hit(projectile.owner_id) and, only when health becomes zero, call self.scores.record_kill(projectile.owner_id), then remove the projectile.
    - reset(self)->None: restore deep clones of the constructor-supplied initial arena and tanks (position, direction, health, speed), clear projectiles and command_queue, set scores=ScoreBoard(list(self._initial_tanks)), and next_projectile_id=0.
    - winner(self)->str|None: returns the sole surviving tank id only when exactly one remains alive from at least two initial tanks; else None.
    - snapshot(self)->dict: returns only plain dict/list/scalars; arena as dict, tanks as dict of dicts with direction serialized via .name, projectiles similarly, scores as a dict with hits, kills, and per-player score mapping, and winner as scalar id or None.
- Module tank_battle/configs.py:
  - build_default_demo()->Game: constructs exactly Arena(8,5,[]) and two tanks: Tank("p1","P1",1,2,Direction.E,3,1) and Tank("p2","P2",6,2,Direction.W,3,1); builds Game and returns it.
- Module tank_battle/__init__.py:
  - Explicitly import and re-export exactly these public symbols: Game, Arena, Obstacle, Rect, Tank, Projectile, ScoreBoard, Direction, Command, MoveForward, RotateLeft, RotateRight, RotateTo, Fire, and build_default_demo; __all__ lists those exact names; no wildcard imports and no nested aliases such as Game.Arena; no package attribute named commands.
- Module Main.py:
  - from tank_battle import build_default_demo, RotateRight
  - Function run_demo()->dict: constructs game=build_default_demo(); literally calls game.queue_command("p1", RotateRight()) with a command instance (not the string "RotateRight"), then calls game.tick() exactly once, returns game.snapshot(). main() prints that snapshot and is called under if __name__=="__main__".

Deterministic fixtures (repeat verbatim):
- Arena(8,5,[])
- Tank("p1","P1",1,2,Direction.E,3,1)
- Tank("p2","P2",6,2,Direction.W,3,1)

Projectile same-tick movement rule: Fire first creates a projectile at barrel_ahead; tick one therefore leaves it at (3,2); tick two moves it to (4,2) and hits p2. A test expecting (2,2) after tick one is forbidden.

Scoring call literals: self.scores.record_hit(projectile.owner_id) and self.scores.record_kill(projectile.owner_id) on kill only.

Winner rule: winner returns the sole surviving tank id only when exactly one remains alive from at least two initial tanks.

Reset fixture rule: capture initial snapshot immediately after Game construction with no queued Fire and no tick; after manipulating state, reset() must restore deep clones and zeroed scores as {"p1":0,"p2":0}; next_projectile_id==0.

Import graph policy: foundational modules never import engines or entrypoints; game.py directly imports command classes via the literal line; __init__.py only re-exports public symbols; Main.py imports only build_default_demo and RotateRight.

## Program call flow

sequenceDiagram
    participant M as Main
    participant C as configs.build_default_demo
    participant G as Game
    participant SB as ScoreBoard
    M->>C: build_default_demo()
    C-->>M: Game(arena:Arena, tanks:dict[str,Tank])
    M->>G: queue_command("p1", RotateRight())
    M->>G: tick()
    G->>G: stable-sort commands by player id
    G->>G: isinstance dispatch MoveForward/RotateLeft/RotateRight/RotateTo/Fire
    G->>G: spawn projectile on Fire at barrel_ahead if free
    G->>G: move all projectiles same tick by speed; resolve collisions; record_hit/record_kill
    M->>G: snapshot()
    G-->>M: dict {arena,tanks,projectiles,scores,winner}
    M->>M: print(snapshot)
    note over G: winner returns sole surviving id only when exactly one remains alive from at least two initial tanks
