## Implementation approach

Bob here. We'll deliver a deterministic, headless, medium-size Java 11 Maven repository that strictly adheres to the protocol. The architecture separates immutable values (Position, Orientation, Command) from mutable entities (Tank, Projectile) and environment-free orchestration (GameEngine) with scoring (ScoreBoard) and layout (ObstacleMap, Arena). Main is a thin, non-interactive demo that prints one concise snapshot and exits. We use no Java Stream API and keep all classes in the default package as required. GameEngine enforces lexicographic tank-id ordering, one-command-per-live-tank per tick, same-tick projectile advance and collision, and strict ownership and defensive-copy semantics. Reset reassigns the current arena via this.arena = initialArena.copy(), reconstructs this.tanks from initial snapshots without streams, clears projectiles and command queues, and calls scoreBoard.reset(initialTanks.keySet()). Tests are JUnit Jupiter (Surefire 5-capable) with exactly three concise cases: Main smoke, blocked-move/turn/reset, and hit/kill fixture (Position(1,2) -> spawn (2,2) -> hit (3,2)).
