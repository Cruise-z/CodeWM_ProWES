## Implementation approach

Bob here. We'll preserve C++ protocol files exactly: CMakeLists.txt, src/Main.cpp as the runtime entry, and tests/test_main.cpp as the single test file. The core domain is split into small, concrete, reusable modules with 1:1 include/*.h and src/*.cpp pairs: Geometry (grid and direction utilities), Entities (Arena, Tank, Projectile), and Game (orchestration of ticks, commands, collisions, scoring). The runtime demo remains thin and non-interactive. All domain logic is pure and deterministic: no IO, no OS-specific behavior, no randomness, and no timing. Tests include headers only, link against the core library, and remain headless/offline. The architecture targets 9 files to meet the 8–10 file goal while keeping responsibilities clear and minimal.

## Program call flow

sequenceDiagram
    participant M as Main (src/Main.cpp)
    participant G as Game (include/Game.h)
    participant A as Arena (include/Entities.h)
    participant T as Tanks (include/Entities.h)
    participant P as Projectiles (include/Entities.h)
    M->>G: Game(width,height)
    M->>G: reset()
    M->>G: arena().addObstacle(...)
    M->>G: queueCommand(tank0, Fire/Move/...)
    loop fixed ticks
        M->>G: tick()
        G->>T: apply commands (rotate/move/fire)
        G->>P: move projectiles
        G->>T: resolve collisions and apply damage
        G->>G: update scores/winner
    end
    M-->>M: exit deterministically

## Protocol Preservation Notes

Build file: CMakeLists.txt. Runtime entry: src/Main.cpp. Test target: tests/test_main.cpp. Test command: ctest --test-dir build --output-on-failure. Exactly one protocol-level test file is used.

## Anything UNCLEAR

Assumptions made for determinism: origin at (0,0) top-left with x increasing right and y increasing down; default tank health=3; damage per hit=1; one projectile spawned per Fire command if muzzle cell is in-bounds and free of obstacles/tanks; no fire rate limiting beyond cell occupancy; winner is set to the opponent when one tank reaches 0 health; if both die in the same tick, winner remains unset.
