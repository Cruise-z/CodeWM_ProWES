## Implementation approach

Architect Bob designs a minimal, deterministic Java 11 Maven repository for a headless Flappy Bird core. Protocol-required files are preserved exactly: pom.xml, src/main/java/Main.java, and a single test at src/test/java/MainTest.java. All classes are in the default package with no package declarations and live directly under src/main/java. The runtime entry Main.java remains thin: it constructs Game, performs one standalone game.tick() call (ignoring its boolean result), then prints getters (birdY, birdVy, ticks, score, pipe count). The core domain is split into concrete files: Bird (physics), RNG (seeded randomness), PipePair (obstacles), CollisionDetector (pure collision rules), ScoreSystem (pure scoring rule), Game (orchestration). There is no GUI, no frameworks, and no external dependencies beyond JUnit Jupiter for tests. Physics, RNG, scoring, tick order, spawn timing, and Main invocation strictly follow the provided fixtures.

Full API specification (repeated):
- Coordinates: x increases rightward; y increases downward. Gravity is +0.5 per tick; flap sets vy to -8.0; clamp velocity to [-10.0,10.0].
- Bird(double startY): y=startY, vy=0.0; applyGravity(): vy=clamp(vy+0.5, -10.0, 10.0); integrate(): y+=vy; flap(): replace vy with -8.0.
- Game(long seed) delegates to Game(seed, 400.0, 600.0, 100); starts RUNNING with bird y=worldHeight/2.0 and vy=0.0; pipes list initially empty until spawn at completed tick 100.
- Tick order: one running tick calls Bird.applyGravity() then Bird.integrate(); collision is tested on resulting unclamped position. Game.tick first calls hitBounds(bird, 30.0, worldHeight), then per pipe calls hitPipe(bird, 30.0, 30.0, pipe, worldHeight). Tick increments ticks exactly once; spawn occurs when ticks % spawnInterval == 0 (first spawn on completed tick 100). Game must not clamp the bird before CollisionDetector reports bounds hit.
- Game API: boolean tick(), void reset(long seed), void flapBird(), double birdY(), double birdVy(), long ticks(), int score(), java.util.List<PipePair> pipes(). No aliases.
- RNG: stores constructor seed in final long originalSeed; seed() returns originalSeed without consuming RNG; nextDouble()/nextInt(int bound) delegate directly to stored java.util.Random; Game has private RNG rng (mutable by reset).
- Scoring: ScoreSystem.passedPipe(double birdX, PipePair pipe) returns true exactly once when pipe.x()+pipe.width()<birdX; marks pipe scored via pipe.markScored(); Game checks scoring before removing off-screen pipes.
- Collision: hitBounds(Bird bird, double birdHeight, double worldHeight) and hitPipe(Bird bird, double birdWidth, double birdHeight, PipePair pipe, double worldHeight). Top overlap: bird.y()<pipe.gapY() && bird.y()+birdHeight>0.0. Bottom overlap: bird.y()<worldHeight && bird.y()+birdHeight>pipe.gapY()+pipe.gapHeight(). Never compare any y with pipe.x(). Game.tick calls these exact signatures per the described order.
- Main: must call game.tick() as a standalone statement, ignore its boolean result, then print getters; no embedding in any value expression.

Logic Analysis (repeated fixtures enforcement):
- Gravity increases vy by +0.5 (downward) and y increases after integrate() when vy>0. Flap overwrites vy=-8.0 regardless of previous value; clamp is applied in applyGravity only.
- Tick sequence correctness ensures physics applied before collision detection; no clamping is allowed before collision checks. Bound collision uses unclamped y and y+birdHeight.
- Spawn timing: ticks start at 0; after each successful tick increment ticks once; a pipe is spawned when ticks % 100 == 0; default game has no pipes for ticks 0..99; first spawn occurs on completed tick 100.
- Scoring strictness: ScoreSystem triggers only when trailing edge (pipe.x()+pipe.width()) is strictly less than birdX; only once per pipe via markScored; Game increments score based on this check before any off-screen removal.
- RNG paired streams: seed() is non-consuming; calling a.seed() multiple times does not move the random stream; paired instances produce same nextDouble and nextInt(bound) if their consumption is identical.

Test Scope Plan (repeated fixtures enforcement):
- Provide exactly 2–4 short deterministic JUnit 5 tests in src/test/java/MainTest.java.
- Tests cover: physics fixture (Game(12345L) initial state; after one tick vy=0.5, y=300.5); reset and flap fixture (after reset(12345L), flapBird(), then one tick vy=-7.5, y=292.5); RNG paired stream fixture with seed 98765L; scoring fixture using handcrafted PipePair(100.0,50.0,100.0,150.0,3.0) verifying strict trailing-edge comparison. Tests never index the initial empty pipes list and do not wait for spawn.

Shared Knowledge (repeated rules in tasks):
- Maintain coordinate convention and numeric constants: gravity=+0.5, flap=-8.0, speed clamp=[-10.0,10.0], bird size 30x30, world size 400x600, spawnInterval=100, birdX constant used by Game for scoring and collision.
- Tick order, collision calls signatures and per-pipe loop, RNG contract with non-consuming seed, mutable Game.rng replaced by reset, strict scoring before off-screen removal, first spawn after completed tick 100.

Roles:
- Alice: physics and collisions (Bird.java, CollisionDetector.java).
- Eve: randomness and obstacles (RNG.java, PipePair.java).
- Alex: orchestration and scoring (Game.java, ScoreSystem.java, Main.java, MainTest.java).

## Program call flow

sequenceDiagram
    participant Main
    participant G as Game
    participant B as Bird
    participant C as CollisionDetector
    participant S as ScoreSystem
    Main->>G: new Game(seed)
    Main->>G: tick()
    G->>B: applyGravity()
    G->>B: integrate()
    G->>C: hitBounds(bird, 30.0, worldHeight)
    loop for each pipe
        G->>C: hitPipe(bird, 30.0, 30.0, pipe, worldHeight)
        G->>S: passedPipe(birdX, pipe)
    end
    G->>G: ticks++ and spawn if ticks % 100 == 0
    Main->>G: birdY(), birdVy(), ticks(), score(), pipes().size()
