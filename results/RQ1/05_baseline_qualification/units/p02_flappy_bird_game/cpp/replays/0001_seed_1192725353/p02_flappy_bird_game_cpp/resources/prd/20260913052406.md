## Domain Reasoning

- Bird physics: vertical position and velocity, gravity, flap impulse, boundary clamps
- Deterministic update ticks: dt-driven discrete updates
- Pipes: horizontal movement, fixed width, vertical gap, periodic spawn via RNG boundary
- Collision: axis-aligned rectangles vs bird rectangle
- Scoring: increment when a pipe's trailing edge passes the bird's x, once per pipe
- Game over: triggered on collision or bird leaving play area
- Reset: reinitialize state deterministically
- Randomness boundary: deterministic seeded RNG to generate gap positions independent of domain logic

## Domain Expectations

- Bird updates apply gravity each tick and flap adds upward velocity impulse
- Pipes move left at constant speed and respawn periodically with deterministic gap positions
- Collision detection uses rectangle overlap between bird and pipe rectangles; ground/ceiling are hard limits
- Score increments exactly once when a pipe passes the bird's x and hasn't been scored yet
- Game over state freezes updates except allowing reset
- Reset returns bird to initial position, clears pipes, resets score and game-over flag
- Configuration validation prevents nonsensical parameters (e.g., negative gravity, zero gap height)
- All updates are driven by a supplied dt to remain deterministic in tests

## Product Goals

- Deliver a clean, testable core game logic with deterministic behavior
- Provide a small runtime demo that safely starts and exits
- Keep architecture modular with clear boundaries for RNG/time and domain

## User Stories

- As a player, I want the bird to rise when I flap and then fall due to gravity.
- As a player, I want pipes to move toward the bird with gaps I can pass through.
- As a player, I want the game to end when I hit a pipe or go out of bounds.
- As a player, I want my score to increase when I successfully pass a pipe.
- As a player, I want to be able to reset the game to try again.

## Competitive Analysis

- Original Flappy Bird: iconic mechanics, simple control, constant difficulty curve

- Academic demos of physics-based 2D games: good separation and determinism for testing

Canonical Public API spec (modules, signatures, semantics):
- include/Random.h:
  - struct IRandom { virtual ~IRandom() noexcept = default; virtual double nextUnit() = 0; }.
    Returns a deterministic pseudorandom double in [0,1); no exceptions.
  - class LcgRandom : public IRandom {
      explicit LcgRandom(uint64_t seed);
      double nextUnit() override;
      uint64_t nextUint64();
    }.
    Deterministic 64-bit LCG; nextUnit = nextUint64 / 2^64; no exceptions.

- include/GameConfig.h:
  - struct GameConfig {
      double worldWidth, worldHeight;
      double gravity, flapImpulse, maxFallSpeed;
      double pipeSpeed, pipeWidth, pipeGapHeight, pipeSpawnInterval;
      double birdX, birdWidth, birdHeight;
      static GameConfig Default();
      void validate() const;
    }.
    Default provides sane parameters; validate throws std::invalid_argument when any non-positive, invalid ranges, or birdX out of bounds.

- include/Bird.h:
  - class Bird {
      Bird(double y0, double v0);
      void flap(const GameConfig& cfg);
      void update(double dt, const GameConfig& cfg);
      double y() const;
      double velocity() const;
      double top(const GameConfig& cfg) const;
      double bottom(const GameConfig& cfg) const;
      void reset(double y0);
    }.
    Physics: positive up velocity; gravity reduces velocity; clamp position to playfield.

- include/Pipe.h:
  - struct Pipe {
      double x; double gapY; bool scored;
      explicit Pipe(double x0, double gapY0);
      void update(double dt, const GameConfig& cfg);
      bool isOffscreen(const GameConfig& cfg) const;
      bool hasPassedBird(double birdX, const GameConfig& cfg) const;
      bool collidesWithBird(double birdX, double birdTop, double birdBottom, const GameConfig& cfg) const;
    }.
    Movement left at pipeSpeed; collision if bird rectangle overlaps non-gap regions.

- include/GameState.h:
  - class GameState {
      explicit GameState(const GameConfig& cfg);
      void reset();
      void flap();
      void update(double dt, IRandom& rng);
      int score() const;
      bool gameOver() const;
      const std::vector<Pipe>& pipes() const;
      double birdY() const;
      double birdTop() const;
      double birdBottom() const;
    }.
    Drives all domain updates; spawn pipes via rng; scoring and collision rules; frozen when gameOver.

- include/GameEngine.h:
  - class GameEngine {
      explicit GameEngine(GameConfig cfg, std::unique_ptr<IRandom> rng);
      void reset();
      void flap();
      void step(double dt);
      int score() const;
      bool isGameOver() const;
      double birdY() const;
      const std::vector<Pipe>& pipes() const;
      const GameConfig& config() const;
    }.
    Facade over GameState; coordinates config validation and RNG ownership.
