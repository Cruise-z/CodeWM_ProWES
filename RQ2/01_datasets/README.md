# Datasets and split identity

Released splits are in `../../results/RQ2/01_datasets/splits/`. GitHub-C,
GitHub-Java, MBCPP, MBJP, and MBJSP source JSONL files are present. CSN-Java
and CSN-JavaScript train/validation source files were not present in the final
release workspace; their exact train/validation/test sizes are retained in all
eight training manifests, while clean test observations and the stable selected
UID cohorts are released. Upstream acquisition/preprocessing is documented in
`../source/training/SrcMarker_fresh/README.md`.
