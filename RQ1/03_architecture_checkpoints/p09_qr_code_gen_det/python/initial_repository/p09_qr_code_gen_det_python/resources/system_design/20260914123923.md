## Implementation approach

Preserve protocol files exactly; keep Main.py thin and put reusable logic in a lowercase snake_case package named qr_code. Use Python 3.10-only features and avoid external dependencies beyond pytest. Design an acyclic import graph: qr_code/payload.py and qr_code/matrix.py are foundational and import no project modules; qr_code/codec.py composes payload and matrix; qr_code/render.py imports only validate_matrix from qr_code/matrix.py; qr_code/__init__.py explicitly re-exports the canonical API. Implement a deterministic QR-like codec: payload encodes UTF-8 bytes with an 8-bit length header, MSB-first data bits, and an 8-bit checksum; matrix uses a fixed 21x21 grid with three 5x5 finder patterns and row-major data placement; codec composes the flow; render produces a 21-line ASCII string; detect probes safely. Automated tests are deterministic, headless, and cover demo wiring, Unicode roundtrip including strict trailing-zero padding validation, rendering dimensions, and corruption/malformed rejections. Ensure every function signature and behavior matches the non-negotiable checklist, including direct extract_bits-to-unpack_payload decoding and exact counts (366 non-finder bits) and constraints (max 40-byte payload).
