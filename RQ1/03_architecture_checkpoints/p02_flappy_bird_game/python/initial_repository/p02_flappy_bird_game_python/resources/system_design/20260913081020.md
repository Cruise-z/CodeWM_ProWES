## Implementation approach

Preserve protocol files exactly (requirements.txt, Main.py, tests/test_main.py). Keep Main.py as a thin, headless demo that constructs the Game, performs a single flap, steps a few ticks, prints summary, and exits. Put all reusable logic into a lowercase snake_case package named flappy_bird. Separate pure domain logic (physics integration, scoring decision helper, collision rules) from orchestration (Game) and environment-dependent code (Main.py). Ensure an acyclic import graph: config has no imports; pure rules (physics, scoring, collision) only depend on typing and config types; domain entity (pipes.py) defines Pipe; orchestration (game.py) imports config, physics, scoring, collision, and pipes; __init__.py re-exports stable API symbols. Provide a single canonical public API surface via flappy_bird: Game, Pipe, Config, and the pure helper is_pipe_scored(bird_x: float, pipe_right_edge: float, already_passed: bool) -> bool. Tests remain headless-friendly by importing and exercising pure functions and the Game without any GUI or I/O. The scoring helper is unit-tested directly with handcrafted parameters; other tests validate state transitions, flap semantics, physics order, scoring order, and that passed remains visible until off-screen removal. Python version target is 3.10; avoid 3.11+ features. No external dependencies beyond pytest.

%% Full API behavioral rules (applies to Game, Scoring.is_pipe_scored):
%% - States: 'ready', 'running', 'game_over' only.
%% - flap(): in 'ready' atomically sets state to 'running' and immediately applies config.flap_impulse to vy; in 'running' reapplies the impulse; in 'game_over' no-op.
%% - Step order while 'running': (1) vy := clamp(vy + gravity, -max_vy, max_vy); (2) y := y + vy; (3) move pipes; (4) score every unpassed pipe whose right edge is strictly left of config.bird_x exactly once using is_pipe_scored; 'passed' remains true while pipe remains in pipes_readonly(); (5) remove off-screen pipes only after scoring pass.
%% - Scoring helper signature is fixed and pure: is_pipe_scored(bird_x: float, pipe_right_edge: float, already_passed: bool) -> bool.


## Program call flow

sequenceDiagram
    participant M as Main.py
    participant G as Game
    participant P as Physics
    participant S as Scoring
    participant C as Collision

    M->>G: __init__(config)
    M->>G: flap()
    loop few ticks
        M->>G: step()
        G->>P: integrate_vy(vy, gravity, max_vy)
        P-->>G: new_vy
        G->>G: update y by vy
        G->>G: move pipes by -pipe_speed
        G->>S: is_pipe_scored(bird_x, pipe.right_edge(), pipe.passed)
        S-->>G: bool (score now?)
        alt collision check needed
            G->>C: hits_bounds(y, ceiling, floor) or hits_pipe(bird_x, y, pipe)
            C-->>G: bool
            alt collision
                G->>G: state := 'game_over'
            end
        end
        G->>G: remove pipes off-screen (after scoring)
    end
    M->>G: status()
    G-->>M: {state, y, vy, score, pipes}
