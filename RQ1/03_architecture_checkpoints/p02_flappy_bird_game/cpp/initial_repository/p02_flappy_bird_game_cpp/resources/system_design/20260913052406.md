## Implementation approach

Preserve protocol-required files exactly. Build a single core library from all non-Main sources and link both the demo executable and the single test executable against it via CMake. Separate pure domain logic (Bird, Pipe, GameState) from environment boundaries (seeded RNG adapter and runtime main). Keep headers self-contained with the standard includes they need. Drive all updates with a deterministic dt and a seeded RNG boundary interface (IRandom) to ensure reproducible unit tests. The runtime entry is a small, non-interactive, headless simulation demo that steps the engine deterministically and prints final status, then exits. Tests are concise, deterministic, headless, and assert externally visible behavior through the canonical public API declared under include/.

## Program call flow

sequenceDiagram
    participant M as Main (src/Main.cpp)
    participant GE as GameEngine
    participant GS as GameState
    participant B as Bird
    participant P as Pipe(s)
    participant R as IRandom (LcgRandom)

    M->>GE: construct(GameConfig::Default(), make_unique<LcgRandom>(42))
    loop Fixed ticks
        M->>GE: step(dt)
        GE->>GS: update(dt, *rng)
        GS->>B: update(dt, cfg)
        alt Spawn due
            GS->>R: nextUnit()
            R-->>GS: u in [0,1)
            GS->>P: create Pipe(worldWidth, gapY)
        end
        GS->>P: update(dt, cfg) for each
        GS->>GS: check pass -> score++ (once)
        GS->>GS: check AABB collisions and bounds -> gameOver?
    end
    M->>GE: flap() at intervals
    GE->>GS: flap()
    M-->>M: print final score and state
