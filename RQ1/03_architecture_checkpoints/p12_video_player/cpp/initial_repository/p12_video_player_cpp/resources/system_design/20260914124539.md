## Implementation approach

Preserve protocol files exactly. Keep runtime entry thin and non-interactive. Split the domain into small C++17 modules with include/*.h and src/*.cpp pairs: time boundary (IClock, ManualClock, MonotonicClock), media metadata, playlist, player state and logic, and a tiny runtime App. Separate pure domain logic from environment: Player, Playlist, MediaMetadata are pure; ManualClock is deterministic; MonotonicClock is environment-touching but not used in tests; Main is tiny. Tests are headless and deterministic, drive ManualClock directly, and include only headers. Enforce the fixed-width integer contract strictly: each header that names a signed 64-bit integer directly includes <cstdint> and spells std::int64_t; IClock.h begins with #include <cstdint> and declares virtual std::int64_t now_ms() const noexcept = 0;. Derived clocks override exactly that signature with identical const and noexcept in headers and sources. The build uses one CMakeLists.txt: build a core library from all src/*.cpp except src/Main.cpp; link a demo executable and a single self-contained test executable; enable_testing() and add_test().
