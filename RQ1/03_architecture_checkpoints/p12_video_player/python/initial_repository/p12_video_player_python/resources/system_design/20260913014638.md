## Implementation approach

Preserve protocol-required files exactly: requirements.txt, Main.py, tests/test_main.py. Keep Main.py a thin, non-interactive bootstrap that constructs a playlist, a deterministic ManualClock, and a Player, performs a few scripted operations, and exits. Place reusable modules in a lowercase snake_case package named video_player. Separate pure domain logic (media metadata, playlist rules, playback state transitions, seeking, volume/mute) from environment/runtime concerns. Provide a headless, deterministic clock abstraction with a tick-driven model: the Player subscribes to a provided clock and advances only on ticks. Tests drive time deterministically by calling ManualClock.tick(...) directly; no GUI, audio, filesystem, or network. Use only pytest as an external dependency. Ensure an acyclic import graph: errors -> media -> playlist -> player; clock is orthogonal and imported by player only; __init__.py only re-exports submodule symbols.

## Program call flow

sequenceDiagram
    participant Main as Main.py
    participant VP as video_player (API)
    participant C as ManualClock
    participant P as Player
    participant PL as Playlist
    participant M as Media

    Main->>M: construct Media(id, title, duration)
    Main->>PL: construct Playlist([Media,...])
    Main->>C: construct ManualClock()
    Main->>P: construct Player(playlist=PL, clock=C)
    Main->>P: play()
    Main->>C: tick(1.0)
    C-->>P: on_tick(delta=1.0)
    P->>P: advance position; clamp; maybe stop at end
    Main->>P: seek(5.0)
    Main->>P: pause()
    Main->>C: tick(2.0)
    C-->>P: on_tick(delta=2.0) (no-op while paused)
    Main->>P: next_media(); play()
    Main->>C: tick(999.0)
    C-->>P: on_tick(delta=999.0) (stop at end)
    Main-->>Main: exit
