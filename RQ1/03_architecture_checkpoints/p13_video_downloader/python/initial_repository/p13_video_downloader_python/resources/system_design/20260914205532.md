## Implementation approach

Preserve protocol files exactly. Keep Main.py thin and headless. Implement all reusable logic in a lowercase snake_case package video_downloader with an acyclic import graph. Use only Python 3.10-compatible language features; avoid 3.11+ APIs. Provide a deterministic, offline FakeTransferAdapter that never performs I/O and a synchronous DownloadQueue with pre-start cancellation only. Enforce strict URL and format validation, safe filename sanitation, and deterministic unique naming. Tests are concise, deterministic, and headless, with exactly four cases covering: demo completion 12/12; URL and format validation errors; naming fixtures; and two-job queue with pre-start cancellation (job1 cancelled 0/12, job2 completed 8/8 final_name b.mp4). Public API is exposed solely via video_downloader.__init__ and Main.run_demo().

## Program call flow

sequenceDiagram
    participant M as Main.run_demo
    participant API as video_downloader (public API)
    participant FTA as FakeTransferAdapter
    participant Q as DownloadQueue

    M->>API: DownloadRequest(url, fmt="mp4")
    M->>FTA: __init__(mapping={"https://example.com/clip": (12,4)})
    M->>Q: __init__(adapter=FTA)
    M->>Q: enqueue(request)
    M->>Q: process_all()
    Q->>FTA: total_bytes(req)
    Q->>API: Progress(total=12)
    Q->>FTA: transfer(req, progress, token)
    FTA->>API: Progress.update(chunk) (loop until total)
    FTA-->>Q: TransferResult(bytes_transferred=12, final_name="clip.mp4", completed=True)
    Q-->>M: get_status(job_id)
    M-->>M: return status dict
