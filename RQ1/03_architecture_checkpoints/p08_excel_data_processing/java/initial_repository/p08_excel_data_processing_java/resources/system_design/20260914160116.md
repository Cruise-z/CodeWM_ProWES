## Implementation approach

Bob (Architect) proposes a minimal, deterministic, headless Java 11 Maven project that strictly follows the protocol. The runtime entry (Main.java) is thin and non-interactive. All domain logic lives in small default-package classes under src/main/java. The build declares only JUnit Jupiter (test scope) and a JUnit 5-capable Surefire plugin. The core spreadsheet model uses immutable/defensive entities (Cell, Row, Sheet, Workbook), deterministic counters (ProcessingReport), simple CSV I/O (CsvIO) with exactly two static methods, and pure rules for parsing, filtering, sorting, and aggregations. Java streams are forbidden; all traversals use loops and ArrayList. Tests are headless and deterministic in one JUnit 5 file (MainTest.java) with exactly three tests covering: runtime invocation, a three-row pipeline (import, filter, sort, sum), and a four-row invalid/round-trip pipeline (sum once, export, re-import). Each logically separate operation uses a fresh ProcessingReport as mandated.
