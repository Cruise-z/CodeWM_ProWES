## Implementation approach

Preserve protocol files exactly: CMakeLists.txt, src/Main.cpp, tests/test_main.cpp. Build a clean, C++17 core library exposing deterministic 2048 mechanics with a small, headless runtime demo. Split domain concerns into concrete modules: Board (4x4 grid), Move (slide/merge rules and direction), Spawner (deterministic tile placement), and Game (score, win/loss, reset, orchestration). Keep Main thin and environment-dependent; all core logic is pure and testable. Headers are self-contained and include their own standard headers. All size/index types use std::size_t with explicit <cstddef> includes. Tests are concise (2–3), headless, and deterministic; they include only headers, cover runtime wiring (Game) and a representative core rule (line processing).

## Program call flow

sequenceDiagram
    participant Main as Main.cpp
    participant G as Game
    participant M as Move
    participant S as Spawner
    Main->>G: Game g; g.reset()
    Note right of G: Reset clears board and calls S.initialFill()
    G->>S: initialFill(board)
    S-->>G: board with two 2s (deterministic)
    Main->>G: g.move(Left)
    G->>M: applyMove(board, Left)
    M-->>G: BoardMoveResult{moved, scoreGained}
    alt moved == true
        G->>S: spawn(board)
        S-->>G: spawn success/failure
        G->>G: update score, check win/loss via board.maxTile and M.hasLegalMove
    else moved == false
        G->>G: no spawn, no score change
    end
    Main-->>Main: print board/score/state and exit
