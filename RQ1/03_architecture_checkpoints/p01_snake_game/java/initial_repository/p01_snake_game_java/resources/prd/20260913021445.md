## Domain Reasoning

- Entities: Grid (width, height), Position (x,y), Direction (UP, DOWN, LEFT, RIGHT), Snake (ordered body cells), Food (single position), Score, Game state (RUNNING/GAME_OVER)
- Rules: Snake advances one cell per tick in its current direction; immediate reversal is disallowed to prevent self-collision artifacts
- Placement: Food must appear on an empty cell not occupied by the snake body; randomness must be controllable for tests
- Growth: On eating food, snake grows by not removing its tail in that step; score increases deterministically
- Collisions: Hitting walls or the snake's own body ends the game
- Reset: Game can be reset to a known initial state with configurable dimensions and RNG seed/source

## Domain Expectations

- Grid-based movement uses integer coordinates with origin at top-left (0,0); y increases downward; bounds [0..width-1], [0..height-1]
- Direction update API rejects opposite direction of current motion (e.g., LEFT cannot switch to RIGHT immediately)
- Food random placement uses an injected Random-like interface to ensure determinism in tests
- Tick processing returns a result indicating move outcome: moved, ate food, or game over
- Score increments by a fixed amount per food consumed (e.g., +1)
- Game state exposes immutable snapshots for reading without allowing external mutation
- Reset returns the game to a fresh state with snake length 1+ and new food placement
- API validates inputs (e.g., positive grid size) and throws IllegalArgumentException for invalid parameters

## Product Goals

- Deliver a clean, deterministic core Snake engine with well-defined public API
- Ensure build and test pass reliably via Maven/JUnit 5 under headless conditions
- Keep runtime entry minimal and safe, demonstrating the engine without interactive loops

## User Stories

- As a player, I want the snake to move on a grid and grow when eating food so that my score increases.
- As a player, I want direction changes to be responsive but not allow immediate reversal to avoid unfair deaths.
- As a player, I want the game to end when I hit a wall or myself so the rules feel consistent.
- As a player, I want to reset the game quickly to play again with a clean starting state.
