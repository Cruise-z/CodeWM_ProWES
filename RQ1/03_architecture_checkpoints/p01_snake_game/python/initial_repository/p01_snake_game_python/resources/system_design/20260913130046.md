## Implementation approach

Preserve protocol files exactly: requirements.txt with pytest only; runtime entry Main.py thin; single test file tests/test_main.py using python -m pytest -q. Put all reusable modules in a lowercase snake_case package named snake_game. Maintain an acyclic import graph: direction -> none; grid -> none; snake -> direction+grid; collision -> grid; random_provider -> grid; food -> grid+random_provider; game -> direction, grid, snake, collision, food, random_provider. Keep Python 3.10 only: do not use typing.Self, StrEnum, exception groups, or any Python 3.11+ APIs. For any module with forward references to its own types, start with from __future__ import annotations; otherwise, avoid forward references or quote them. Full API specification details and exact contracts repeated here:
- snake_game/direction.py owns Direction(Enum) and no other module duplicates deltas. Direction values must map to exact integer tuples: UP=(0,-1), DOWN=(0,1), LEFT=(-1,0), RIGHT=(1,0). Expose delta(self) -> tuple[int, int] returning (dx,dy), and is_opposite(self, other: Direction) -> bool rejecting immediate reversal.
- snake_game/grid.py defines only Position and Grid. Position is immutable/hashable with fields x:int, y:int. Grid validates width,height > 0 and provides in_bounds(pos: Position) -> bool. It must never mention or import Direction.
- snake_game/snake.py imports Direction and Position directly. Provide Snake mutable API: turn(requested: Direction) -> bool (reject immediate reversal), next_head() -> Position using self.direction.delta(), and advance(grow: bool) -> None mutating the body in place.
- snake_game/collision.py operates only on explicit Position/Grid/body arguments; no direction-to-delta mapping replication. Provide hit_wall(grid: Grid, pos: Position) -> bool and hit_self(body: list[Position], next_head: Position, grow: bool) -> bool treating moving into the departing tail as safe when not growing.
- snake_game/random_provider.py provides RandomProvider with deterministic behavior. It can be constructed with a pre-seeded sequence of Position objects for tests and demo. It must not depend on non-standard libraries.
- snake_game/food.py uses grid+random_provider to place food not on the snake body, only after consumption.
- snake_game/game.py exposes Game(grid: Grid, rng: RandomProvider, start: Position, direction: Direction). No second mandatory initialization call; the constructor initializes a live game. Public methods: turn(requested: Direction) -> bool, step() -> None, reset() -> None, state() -> dict, is_over() -> bool, score_get() -> int. Step semantics: compute next_head once; check wall and self collision prior to mutation; treat moving into departing tail as safe when not growing; advance once; increment score only on food; place new food only after consumption.
- Main.py defines main(), creates a deterministic RandomProvider and a valid Game, performs at most two safe steps, prints one snapshot, exits, and runs main() only under the __name__ guard.
- Tests must be deterministic and concise (2–4). Import only canonical public API symbols explicitly (no wildcards). Direction must be imported explicitly.
Deterministic fixtures:
- No-growth fixture: grid 10x10, start Position(5,5), direction RIGHT, deterministic food Position(1,1): one step results in snake [(6,5)], food (1,1), score 0, over False.
- Growth fixture: grid 10x10, start Position(5,5), direction RIGHT, deterministic food sequence [Position(6,5), Position(1,1)]: one step results in snake [(6,5),(5,5)], new food (1,1), score 1, over False.
Headless-friendly tests: no GUI, IO, or network; all pure domain logic validated via Game.state and related APIs.

    G->>RP: next_position(grid)
    RP-->>G: initial food Position
    M->>G: step()
    G->>S: next_head()
    S-->>G: Position(x+dx, y+dy)
    G->>C: hit_wall(grid, next_head)
    C-->>G: False (safe)
    G->>C: hit_self(body, next_head, grow)
    C-->>G: False (safe)
    G->>S: advance(grow)
    alt food consumed
        G->>F: place_food(grid, rng, occupied)
        F->>RP: next_position(grid)
        RP-->>F: new food Position
        F-->>G: new food Position
        G->>G: score += 1
    end
    M->>G: state()
    G-->>M: {width,height,snake,food,score,over,direction}
    M-->>M: print snapshot
    M-->>M: exit
