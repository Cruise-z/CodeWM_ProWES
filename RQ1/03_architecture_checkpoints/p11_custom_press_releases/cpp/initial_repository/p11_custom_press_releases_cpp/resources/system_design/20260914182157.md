## Implementation approach

Preserve protocol files exactly. Build a small core library of pure domain modules: templating, validation, lifecycle PressRelease entity with version history, rendering, and search indexing. Keep runtime entry thin and deterministic: compose a release, validate, transition states, render, index, search, and print a short demo. Separate environment-dependent runtime (Main.cpp) from pure logic modules. Use only C++17 standard library and CMake. Expose a canonical, cohesive API via headers in include/*.h and implement in src/*.cpp, with directional dependencies: foundational types (Clock, VersionHistory) first, then TemplateEngine and Validator, then PressRelease, followed by Renderer and SearchIndex. Tests include headers only and assert deterministic, externally visible behavior.
