## Implementation approach

Preserve the protocol files exactly and implement a small, deterministic Java 11 codebase with no external runtime dependencies beyond JUnit Jupiter for tests. Keep Main.java as a thin runtime entry that wires an in-memory repository and service and runs a fixed demo. Model the domain with Priority and Task, enforce validation and normalization rules within Task, isolate persistence via TaskRepository and InMemoryTaskRepository, and keep filtering and sorting as pure utilities (TaskFilter and TaskSorter). TodoService orchestrates create/edit/delete/complete/list/summary and strictly follows the specified create order and error behaviors. Use exactly the required file list, default unnamed package, explicit imports, and banned-feature constraints (no streams, Optional, builders, custom clocks, or advanced comparator APIs). Provide one concise JUnit Jupiter test file with exactly four tests (runtime/demo, CRUD/validation, filter/sort, summary) that run headlessly and deterministically under mvn -q test. Maven is configured for Java 11 UTF-8, JUnit Jupiter 5.9.3 (test scope), and Surefire 3.1.2 with useModulePath=false.
