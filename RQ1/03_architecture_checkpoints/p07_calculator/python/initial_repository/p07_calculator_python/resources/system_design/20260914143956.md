## Implementation approach

Bob (Architect) proposes a small, acyclic Python 3.10 package that cleanly separates concerns: foundational errors and history; a tokenizer that is the sole owner of token classes and scans input deterministically; a pure engine implementing shunting-yard and RPN evaluation; a thin API that composes tokenizer and engine and integrates History; a thin entrypoint. Preserve protocol files exactly (requirements.txt, Main.py, tests/test_main.py). Keep runtime entry minimal and headless. Use only standard library plus pytest in requirements. Adhere strictly to import direction errors/history -> tokenizer -> engine -> api -> __init__/Main/tests. Enforce tokenizer ownership: only Token, NumberToken, OpToken, LParenToken, RParenToken, and Tokenizer are defined in calculator/tokenizer.py, with the only project import being 'from .errors import TokenizationError'. Ensure engine.py literally imports tokens via 'from .tokenizer import Token, NumberToken, OpToken, LParenToken, RParenToken'. Avoid Python 3.11+ APIs. Ensure every scanning branch advances or raises. Evaluate rejects blank input with ParseError and appends exactly one History record on success. Tests are deterministic, concise, and rely only on the canonical public API and run_demo. Each file stays under ~150 LOC.

## Domain Mapping

- ['calculator/errors.py defines foundational exceptions', 'calculator/errors.py', 'Defines CalculatorError (base), TokenizationError, ParseError, EvaluationError; no external imports needed other than builtins; no dependencies on other project modules.']
- ['calculator/history.py immutable, append-only history', 'calculator/history.py', 'History maintains an internal list of (expression, result). add appends; records returns a shallow copy; __len__ returns count. No imports from other project modules.']
- ['calculator/tokenizer.py sole owner of token classes and tokenizer', 'calculator/tokenizer.py', "Defines Token (marker), NumberToken(frozen, value: float), OpToken(frozen, op: str), LParenToken(), RParenToken(). Tokenizer.tokenize(expression: str)->list[Token] ignores whitespace, recognizes numbers (integers/decimals), operators + - * /, parentheses. Unary + or - at start or after operator or '(' must fold into the following number; malformed numbers and invalid characters raise TokenizationError. Every branch advances index or raises to avoid stalls. Only project import: from .errors import TokenizationError. The forbidden strings 'from .tokenizer import' and 'from calculator.tokenizer import' must not appear."]
- ['calculator/engine.py parsing and evaluation', 'calculator/engine.py', 'Literally imports: from .tokenizer import Token, NumberToken, OpToken, LParenToken, RParenToken. Imports ParseError and EvaluationError from .errors. Implements to_rpn(tokens:list[Token])->list[Token] using shunting-yard with precedence (* and / > + and -) and parentheses, raising ParseError for malformed expressions (e.g., mismatched parentheses, operator misuse). Implements eval_rpn(rpn:list[Token])->float using a float stack; performs operations; raises EvaluationError for division by zero and stack errors.']
- ['calculator/api.py public API composition', 'calculator/api.py', 'Imports Tokenizer, Token from .tokenizer; to_rpn, eval_rpn from .engine; History from .history; ParseError from .errors. tokenize(expression) thinly delegates to Tokenizer().tokenize. evaluate(expression, history=None): rejects blank/whitespace-only with ParseError; tokenizes; to_rpn; eval_rpn; on success, if history provided, appends exactly one record; propagates TokenizationError, ParseError, EvaluationError unchanged; returns float.']
- ['calculator/__init__.py public re-exports', 'calculator/__init__.py', 'Explicitly re-exports evaluate, tokenize from .api; History from .history; CalculatorError, TokenizationError, ParseError, EvaluationError from .errors. No extra aliases.']
- ['Main.py thin runtime entry', 'Main.py', "Uses 'from calculator import evaluate, History'. Defines run_demo()->dict: evaluates one fixed expression using a History, returns a dict with expression, result, history_len. Under __name__ guard, prints one concise value (e.g., result) and exits. No input loops, no network/FS/time."]
- ['tests/test_main.py concise protocol-level tests', 'tests/test_main.py', "Exactly three pytest tests using only 'from calculator import evaluate, tokenize, History, CalculatorError, TokenizationError, ParseError, EvaluationError' and 'from Main import run_demo'. Tests: (1) run_demo returns a dict and evaluate('2 + 3 * 4') == 14.0; (2) a single History records exactly ('(1 + 2) * 3', 9.0) and len(tokenize('1 + 2.5')) == 3; (3) division by zero raises EvaluationError, evaluate('1 @ 2') raises TokenizationError, and blank input raises ParseError. No token construction, isinstance checks, reflection, or internal-module imports."]
