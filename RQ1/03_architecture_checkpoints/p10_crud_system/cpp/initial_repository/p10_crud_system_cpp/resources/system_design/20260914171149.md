## Implementation approach

Preserve the exact 11-file C++17 protocol. Keep runtime entry thin and headless. Implement a deterministic in-memory CRUD system with strict validation and ordering. Use one concrete Record entity, a deterministic ManualClock, a concrete std::map-backed Repository, and a CrudService that encapsulates validation and business rules. No namespaces, no extra files, no external dependencies. Headers are self-contained with exact direct includes. Sources include headers by basename only and never rely on transitive includes. CMake builds a static core library from the four core .cpp files and links both app and test executables. The single test is a main-based, deterministic, offline test covering the three required blocks. The service enforces: non-blank id/name, email must contain exactly one '@' not at edges; create throws runtime_error for duplicates; update throws runtime_error if absent; invalid inputs throw invalid_argument; list is deterministic by std::map key order. ManualClock is the only time source; no wall clock calls. Constructor declarations are only in headers and definitions only in corresponding .cpp files.
