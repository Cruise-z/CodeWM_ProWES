# RQ1 final analysis

The released RQ1 analysis chain is split by evidence type:

- baseline ledgers: `tools/build_rq1_baseline_ledgers.py`;
- evidence validation: `tools/verify_rq1_evidence.py`;
- strength-sweep statistics and figures:
  `results/RQ1/07_strength_sweep/scripts/`;
- detectability statistics:
  `results/RQ1/08_detectability/scripts/build_detectability_table.py`;
- reviewer entry point: `paper_reproduction/reproduce_rq1.sh`.

Final generated outputs are under `paper_reproduction/tables/RQ1/` and
`paper_reproduction/figures/RQ1/`.
